# Seedance 中台使用说明

在有缓存原片的案例详情，展开文字旁的「标记或确认区间」，输入起止秒数并确认。团队可以回放同一区间；对应文字变化后需重新核对。自营商品报告中的开场、演示和收尾引用会沿用已确认区间。

内容复用的完整视频分析可在看点、开场、复刻动作、内容递进或结尾旁显示「核对片段」。点击可播放模型指出的原片时间区间，供人工核对。缺少明确区间的案例仍可使用「查看镜头」。

所有页签共用紧凑页头，不再显示旧的框架预览说明。「内容复用」「爆款文案库」「自营商品」「GMV 贡献」「风险表达库」「脚本任务」「异常任务」「Kalodata 查询」「数据接入」保留原页签，导航下方不再重复显示页名、英文小标题或简介，直接进入操作区、列表或状态区。字段说明、费用提示和配置状态仍在对应操作旁显示。试填内容只保留在当前页面会话；添加试填条目后，可在列表工具栏点击「导出试填内容」保留 JSON。

## 自营商品证据链
证据报告按当前选中的拍法统计。关联视频缺少评论证据时，需求和购买阻力卡会显示该拍法的采集或标注状态，可点开追溯到案例。
商品链接的可读名称可补充挂烫机、真空收纳袋等细品类及功率、水箱容量、预热时间、件数等标称信息，可在标签来源中核对。案例尚缺细品类时也会核对已保存的 Apify 或 Kalodata 带货关系，若仅挂一款商品且商品名称能明确识别细品类，可据此自动关联。多商品视频保留待核，人工标签及排除决定优先。
在「竞对与脚本」中，「自营商品」位于「内容复用」之后；「商品与店铺」仍是独立的竞品入口。服务版本不支持自营接口时不显示该标签。
1. 登记店铺、市场、商品 HTTPS 链接、SKU 和已核实规格。根据名称、可识别的 TikTok Shop 链接名称和录入规格自动显示细品类及场景标签。规则无法识别、信息有冲突或只有宽泛标签时保持待确认；编辑时可指定一个细品类，留空恢复自动识别。保存和打开报告不会发起 Kalodata 查询。主图补齐由保存后的后台队列单独执行，不等待图片即可查看报告。
   录入人或管理员可在「查看详情 → 商品链接与资料 → 从链接取数」确认发起单次查询。当前支持美国市场（US）的 TikTok Shop 完整商品链接，以及能直接跳转到公开商品页的 TikTok 官方分享短链。只按准确商品 ID 查询，优先复用过去 7 天的同市场、同 ID 资料；没有有效缓存时，最多调用一次 Kalodata 商品详情，可能消耗 API Credits。不会按关键词替换商品，也不启动评论采集或额外 AI 分析。
   **主图自动补齐**：LAN 工作进程会为新档案和缺图的历史档案排队。仅按市场和准确商品 ID 复用已保存的主图、未过期的图源和已有 Kalodata 详情缓存；不发起新的 Kalodata 查询。已确认的「从链接取数」仍会在同次详情请求中读取图源。图片经允许的公开 HTTPS CDN 下载并转为最长边 560 像素的站内缩略图。对已知的 Shop 图片域，可走系统已配置的本机代理，仍验证公开地址和 HTTPS 证书，不发送站点登录信息。列表和详情会更新缩略图，「商品链接与资料」显示图源、保存时间和等待、重试或待核对状态。人工图优先，未找到图片不影响资料、标签及报告。短暂下载故障最多自动再试两次；无法确认 ID 的历史分享短链请换成完整商品页链接，不重跑已受阻短链。
   **管理员 → 自营商品列表 → 主图图源**：可为中台单独启用或暂停领星 MCP，只读美国站（US）精确商品 ID 的商品分析图字段，不读取销售指标作为证据，不采用相似商品图。启用前需在领星侧授权相应只读能力，独立密钥只在此设置页填写、加密保存、不回显；现有桌面授权不会自动转用。启用后继续处理缺图档案；暂停只停止新的领星读取，已保存的主图与已取得的图源仍可使用。对同一密钥配置和商品只发起一次领星资料读取，未知结果不自动重查；保存状态不代表服务连通或权限验证成功。
   商品 ID、资料来源及日期保存在档案旁；返回的名称、类目、描述和标称规格仅作为第三方资料，可用于生成带来源的标签，不覆盖人工细品类、标签审核、SKU 或已核实规格。资料冲突或不足时显示待确认，仍可复用已核实的关联。结果出来后本地报告会重算，没有匹配案例不代表没有市场需求。短链失效或被拦截时，可换成完整商品页链接；查询或计费结果未知时不重提，在「竞对与脚本 → 异常任务」查看处理记录。
2. 「查看详情 → 自动证据报告」优先匹配现有的 Apify/Kalodata 商品 ID 关系，其次匹配「内容复用」中团队可见的 TikTok 案例的细品类；人工案例品类或商品标签优先于 AI。展示每条关联的理由、内容证据与原案例入口。相同商品 ID 不代表相同 SKU，更不代表自营订单；同细品类不等于同款。录入人或管理员可排除、恢复关联，不改变原案例。报告按现有数据实时重算；刷新不会付费取数。普通扫描限最近更新的 1,000 条，另查商品 ID 和人工链接；最多展示 24 条关联，报告范围内统计，不代表市场全量。观察到不同市场或仅为人工类比的案例不纳入同类汇总。
3. 新商品保存后立即进入证据报告，复用已有案例与评论。按拍摄方式切换六张卡片，分别查看商品适配、用户需求与购买意图、使用场景与触发时刻、购买阻力与内容缺口、拍法表现、可复用镜头。点击卡片查看本类全部指标，点某一条可单独查看来源。有明确时间标记的镜头支持定位播放。拍法表现含独立账号覆盖、近期发布及有可比快照时的播放变化。比例显示已核对样本的命中数与分母。跨品类拍法线索需在商品场景与具体动作上有依据，只作拍摄参考。区间商业估算按市场与时间窗显示。
   商品档案可上传主图。商品页的「商品标签与来源」和视频详情的「标签依据与核对」展示标签从何而来，可确认、驳回或撤销判断。重新分析后同对象同标签沿用已有判断。团队成员可核对团队可见的视频；商品标签由录入人或管理员核对。打开的商品报告约每 30 秒检查本地证据变化，样本更新后重算。可手动刷新。
4. 多维比例仅使用已有有效标注的文本，按视频和评论 ID 去重，评论与抽样回复各有分母，标签可能重叠，缺样本不显示 0%。旧版主题与反例保留，不计入新比例；管理员可在关联案例的「查看评论与反例」中明确确认一次旧样本补标，复用原 AI 启停、异常熔断和每日预算。不自动批量重提，不重复采集，不重试结果未知的任务。
5. 原有手动参考和「添加待验证判断」保留。可分别录入评论、评价、搜索线索、视频观察及自家核实；区分支持、反例和背景。自动报告不写入人工结论。手工比例仍仅按已查验的单批样本计算。档案及证据团队可见，编辑、排除、解除关联或移除证据仅限对应录入人或管理员。未连接 Seller Center，不新增脚本或拍摄流程。

## ScrapeCreators 评论与回复取样
- 「竞对与脚本 → 数据接入」管理员可填写 ScrapeCreators API Key，直接加密保存，不校验余额、不回显、不发请求。保存默认暂停采集和 AI；分别明确确认才能启用。
- 评论采集与评论 AI 仅限「内容复用」中已收录且团队可见的 TikTok 视频。启用采集先回填已有案例；新案例选择「保存并自动分析」时，评论补采与 Apify 单视频基础采集同时入队。竞对账号不触发评论补采，Apify 原有监测不变。只保存案例不立即触发收费请求，可由管理员以后回填。既有监测采样记录保留，但仅在该视频已收录且团队可见时展示或继续处理；已采过的不重复采集，失败及结果未知不自动重跑。
- 默认每天最多 20 次采集请求（北京时间），每视频最多 2 页评论，加最多 2 个回复线程各 1 页；每日请求预算不是固定 credits 报价。输入上限可调；域仅为公开视频评论与回复，不采评价、不回填历史账号快照、不指定评论者国家。空页或无可用文本不代表全平台零评论。
- AI 单独启用，复用已保存的 A6API 密钥，默认每天最多 5 次。只提交所选公开文本、临时编号及评论/回复角色，不发送结构化账号信息、视频、声音和凭据；请留意公开文本本身可能包含个人信息。同一次请求提取主题、反例和可引用的多维信号；生成无效的维度不补零，不覆盖既有主题。程序按已取且去重的文本分别计算评论/回复的命中和分母。打开「内容复用 → 视频案例 → 详情」，顶部「评论样本与 AI 提炼」按单视频显示处理状态、样本数量及主题；可展开支持、反例、多维命中原话和本批文本，或单独刷新结果。仅自营商品报告按所关联的可比案例汇总，比例不代表市场。评论 AI 最多等待响应 180 秒；读取超时只暂停当前视频，报告可展开查看原因。遇到鉴权、额度、限流或其他请求结果未知时，暂停对应队列，核对后恢复后续任务。

## 工程概览分页
工程概览页面代码支持每页20个项目，但当前主导航没有该页面入口。剪辑台「已保存项目」下拉列表按每页50个项目显示并提供上一页/下一页，保留当前项目；视频素材按每页36个显示，范围筛选先于分页。制作台参考素材分类选择器按筛选结果每页36个显示，翻页保留已选项，搜索覆盖已读取的全部素材。以上是前端展示分页，项目摘要及素材列表仍可能全量读取，素材分页接口尚未接入；不是服务端分页。项目选中时按需读取完整工程，项目关联工具栏读取摘要。

## 剪辑台代理预览（Windows，默认关闭）
本地与局域网服务均设置 `HUB_PREVIEW_PROXY=1` 并更新服务后，剪辑时间轴按需排队。轻素材用原片；适合转换的高清或高帧率素材生成最长边 1280 像素的 H.264 30fps 代理。尚未就绪或代理失败时用原片；播放时不会因代理就绪而替换已加载的素材。旋转、HDR、时序可疑等素材不使用不符合检查的代理。制作台的素材查看和下载仍使用原片。
代理沿用素材权限，原素材变化后旧代理不再提供。单任务低优先级处理，导出排队时让行；缓存预算 2 GiB，空间不足时尝试回收旧副本，仍不足则使用原片。导出始终使用原素材，按画幅输出 1080p、30fps。
上线应在所有编辑页面已保存且后台作业空闲的维护窗口执行：确认两个服务进程均继承相同开关，再分别检查本地及局域网入口。部署可用 `restart_timeline_update.py --enable-preview-proxy` 在本机 `state` 写入启用标记，使两端后续重启沿用配置。回退时删除 `state/preview-proxy.enabled`，或给两端显式设置 `HUB_PREVIEW_PROXY=0` 后重启；不需删除原素材、工程或导出。

## 制作台结果预览
结果轮播只在视频成为当前项时才将它交给可见区域加载逻辑；切换到下一条会暂停之前的视频，生成任务轮询在结果未变时不重建播放器。制作台结果预览不使用剪辑代理。

## 剪辑素材库时间筛选接口
剪辑素材库接口支持按创建时间范围筛选；旧的无参数调用仍返回原范围。剪辑台初次打开空白工程且范围为“今日素材”时仅读取当天；切换全部/本项目，恢复含视频或音频片段的工程、加载含片段旧项目时仍会读取全量素材以保留历史引用。旧服务未实现筛选时按原方式全量返回，旧服务返回完整项目时沿用该项目数据。此优化不是全量分页。

## 剪辑台波形缓存
剪辑台音频波形按素材文件版本缓存；权限仍在读取素材时校验。缓存不可写时直接计算，不影响编辑。缓存不是素材备份，当前未设置波形专用自动清理策略。

## 任务历史对账接口
后端提供按指定任务标识批量读取当前状态的接口，并沿用任务可见权限和实时队列信息。制作台尚未接入该接口，任务历史增量刷新尚未完成。

## 制作台素材状态刷新
制作台草稿的素材识别状态按草稿引用的素材批量查询，不改变素材选择范围或归属权限；旧服务尚未提供该接口时回退到原有查询。同一会话避免并发重复轮询，浏览器标签隐藏时暂停，返回后恢复。

## 管理员 Apify 密钥池
「竞对与脚本 → 数据接入」的 Apify API 密钥板块采用公司账号池式表格，由管理员统一新增密钥（名称及Token）、启停和核验。Token加密保存，不回显、不进入日志；普通成员不能查询池详情。新采集任务按最久未使用顺序轮流选择启用密钥，任务在提交前持久绑定密钥，后续查询及数据集读取不换密钥；结果未知不自动重提。停用不影响原任务读取，原有配置首次迁入为legacy，旧运行任务固定使用原密钥。401/403/402/429标记异常，新的任务跳过这些密钥，核验后可恢复；不绕过限流重提任务。
显示官方 `/users/me/limits` 的本月用量、月使用上限及差值（剩余额度估算，非现金余额），带更新时间，缺字段显示未知，失败不伪造零值。可手动刷新，板块可见时约60秒刷新；不是秒级推送，也不保证计费后台零延迟。同账号不同Token共享额度，不应累计。保存及查询余额不运行Actor，不主动开启新付费采集，现有日期范围、费用熔断及监测设置保持不变。

### 任务反馈在哪里看
- **制作台 → 任务记录 → 需处理**：查看 TikTok 公司账号池和 LibTV 的生成异常。可查看账号/额度、参考素材、提交、原任务查询、成片下载或入库等已留存步骤。LibTV 仍在生成且会自动取回时，不计作需处理；原画布与取回入口保持不变。
- **竞对情报与脚本运营 → 异常任务**：按类型、状态或中台编号筛选。本人原有采集、补数、文案及脚本异常，与团队可见案例的 Apify、ScrapeCreators 评论及回复、Kalodata、口播和 AI 处理异常在此查看。可从案例异常跳回原案例。普通等待、暂停和抽样上限不是异常；部分采集确有错误时显示异常，已取得样本仍保留。
- **查看处理记录**是只读操作。在已接入步骤中可看到处理阶段、时间、耗时、排查编号、可用的 HTTP / 接口 / CLI 错误码及平台实际返回的 credits 字段。不保存请求原文、提示词、评论、凭据或签名地址，也不是全站请求账本。历史任务没有逐步记录时只展示已有报错，不推测未留存的阶段和原因。
- 「处理受阻」「失败」「需核对」「结果未知」分别展示。结果未知先核对原平台，不自动重提。收到响应、步骤完成与整项成功分别判断；缺少运行编号或费用字段不代表没有执行或扣费。诊断记录有保留上限；不改变权限、采集范围、配额、暂停开关或原有任务重试策略。

### Apify 提交阶段排查
- 后台进程加载新版后，单账号采集（含爆款文案复查）、合并采集、案例单视频补取的新提交会在服务端 `state/logs/apify-submit.jsonl` 留下分阶段记录。按异常任务的中台任务 ID（`local_id`）查找；时间为 UTC，当前日志与上一份 `.1` 各最多 2 MiB。日志不对网页开放，不回填历史任务。
- `failed` 行包含最后阶段与异常类型：`prepare_payload` / `select_key` / `init_client` / `prepare_request` 分别为准备采集参数、选密钥、初始化 HTTP 客户端和构建请求；`transport` / `read_response` 为连接、发送或读取；`check_http_status` / `update_key_status` 为 HTTP 返回或本地密钥状态更新；`decode_json` / `validate_response` / `validate_run_id` 为响应解码、结构或任务编号校验；`persist_run_id` 为已收到编号但保存未完成。`run_id_saved` 只在本地保存成功后记录。返回状态码、是否收到编号与 SQLite 错误类型可用于关联排查，但不记 Token、请求参数、原始响应、链接或远端编号值。
- `dispatch_started` 只表示进入 HTTP 传输流程，不证明请求到达 Apify；未见状态码或未保存编号不能据此判断未计费。日志只帮助排查，不更改采集配置、配额、用钥或重试策略；不因日志失败或提交结果未知自动重提。

本文是团队共享的产品知识，不赋予 AI 操作权限。AI 只依据实际提供的数据回答；不能因为知道入口就声称已点击、查询素材、提交任务或完成导出。用户账号的记忆、对话、素材权限由后端决定，不能跨账号推断。

## 配音与音频
右侧配音制作使用手动文案，音色库支持名称及语言筛选、试听当前文案、选择与收藏音色。试听文案及正式生成可能消耗 API 额度；平台余额与 API 余额可能独立。完整配音生成 MP3，长文案可能由后台分段处理再合成。生成音频自动进入音频素材，可用于时间轴编辑，上传音频也可使用；生成素材与时间轴音轨不是同一对象。绑定在配音上的字幕跟随配音音轨的最终位置和源区间裁剪，不依赖主轨联动开关；字幕和音频同时选中或组合时不会重复位移，取消绑定或锁定的字幕不自动跟随。
「仅保留人声 / 仅保留背景声」支持单个 1×、1–60 秒视频；同一片段处理中不重复提交。等待期间原片段的来源、速度、区间、位置、音量、锁定等内容改变，或切换项目/撤销替换对象后，结果仅保留在素材库，不自动修改当前时间轴。成功加入音轨与关闭原声作为一次撤销/重做完成；容量不足不会先关闭原声。配音正式生成在保存完成后再次检查当前项目、版本及未保存状态，发生变化时停止提交。

## 导出与飞书
导出前命名视频，导出记录按日期组织，可查看状态、预览成片、下载 MP4。每次导出名字独立于工程名，范围导出以实际选中范围为准。命名或保存期间项目/内容改变会停止本次提交，避免沿用旧选区导出另一个项目。飞书上传是导出之后的独立阶段，等待上传不代表视频已渲染完成。
成员绑定自己的飞书身份与固定云盘主文件夹，启用自动上传后，系统在主文件夹按北京时间创建 YYMMDD 日期子文件夹，例如 2026-11-03 为 261103。设置影响之后提交的导出。失败时先查看归档设置中的具体状态，可重试上传已有成片；不需要因为上传失败重新生成视频。应用可用范围、授权、目录访问权限、网络和本地导出文件都影响结果。

## AI 助理
文字助理可以读当前账号在模块页面可见的已保存数据。例如问「查 @账号 的已采集视频和分析，第 2 页」可查看采集覆盖、当页视频、Kalodata 补数、已有逐字稿、内容复用和评论分析。指定视频编号可查一条视频。长内容保留摘要或片段，源数据可回原页面。查询也支持素材、制作任务、剪辑工程、导出、配音、飞书归档、内容复用、自营商品、商品与店铺、文案、脚本任务、异常任务、账号池、团队成员、操作记录和存储等已登记入口；成员和日志沿用管理员权限。系统只读取已保存数据，不触发新的采集、分析或生成。
助理的查询能力清单从当前已登记且已加载的页面查询入口实时生成，说明直接从本文件读取。新增功能时同步补充本文件。新增业务查询时，在 assistant_data.py 登记已有的权限校验查询入口和允许传给助理的返回字段，加载新版后自动出现在查询清单里。
全局浮动入口，可拖动、调整大小、展开和还原。支持历史对话、新对话、删除对话、文本及图片附件、拖拽文件，并可在输入框直接粘贴剪贴板图片。文字回答显示等待状态和流式呈现效果，完成后可以复制并标记是否有帮助。对话与生图分开；生图走 LibTV Image 2.5 Fast，比例与清晰度从画面设置选择。生成图片可以下载或用作参考；这不代表文字对话具有自动操作制作台的工具权限。
助手「生图」栏显示当前生图账号。部署管理员可为助手单独选用一个已授权的 LibTV 账号，不跟随制作台选项，也不替换原共享授权。配置只影响之后的新请求；取回旧图片优先复用已下载文件，需要远程下载时校验原任务账号，不切到新账号、不重新生成。未另行选择时继续使用「原共享账号」；所选账号不可用时阻止生图，不自动换号。不附参考图时不强制图生图，交由 LibTV 按提示词判断生成模式；有参考图时保留图生图参数。LibTV 确认生图失败且未产出图片时，显示失败结论，不提示取回、不自动重试；结果未确认时仍可查询原任务。
个人记忆由成员在个人记忆入口保存，按账号隔离；团队母版写作规则是共享上下文，仅用于相关创作任务。文字对话还根据当前问题从 GitHub TikTok 知识库的本地固定版本检索最多三篇相关资料片段，作为参考而非强制指令；检索可能不准确或遗漏，仓库更新不会自动同步。文档自动更新不等于母版源文件已自动同步。管理员连接设置不对普通成员开放。

## 管理与排障
公司账号池维护平台连接；团队成员管理维护中台账号及密码重置，不能查看原密码；操作记录辅助排查。管理员与普通成员权限不同。任务错误先区分上传、提交、平台生成、下载、渲染、飞书上传阶段；请求失败不必然意味着额度未扣除。没有日志证据时说明不确定，不猜测具体上游原因。
中台服务运行在执行电脑，关闭服务会影响团队访问。网络超时、凭据失效、磁盘写入失败、空间不足和上游额度不足是不同问题。禁止在说明或对话中暴露密钥、Cookie、数据库记录及其他成员资料。

## 文档维护约定
本文件维护人工确认的操作语义。新增、删除、重命名功能或更改权限时，开发者必须更新相关章节，再执行 python -B sync_ai_readme.py。生成的 README_AI.md 包含代码入口与快捷键清单。文字助理每轮直接读取本文件，优先使用「中台功能速览」，并补充与问题相关的操作段落；涉及键位时也读取快捷键说明。自动提取只能发现代码入口，不能自动证明新功能已经可用；新入口未补充操作说明时，AI 应谨慎说明而非推测。

配音试听请求有 30 秒网络超时、4 分钟状态等待上限。等待超时后，同一页面内再次点击同一文案与音色会查询原任务，提交请求复用幂等标识，不会自动重复生成。音频目录写入失败会明确提示权限问题。

LibTV 失败会记录操作阶段、任务编号、退出码、接口错误码、脱敏错误摘要及排查编号。页面展示排查编号与错误摘要；任务目录 cli-diagnostics.jsonl 保存诊断，写入失败则转存服务错误日志。诊断增强不会自动重试生成；历史已丢弃的原始错误无法恢复。


## 竞对情报与脚本运营（框架预览）
侧栏「竞对与脚本」提供竞对账号、竞品商品、内容复用、GMV 贡献、爆款文案库、风险表达库、脚本任务和数据接入入口。除账号快照、视频案例库、爆款文案库、脚本任务和 Kalodata 已实现部分外，其他预览试填内容仅保留在当前页面内存中，可导出 JSON，刷新或退出清空；飞书、销售归因、提醒和相似内容识别均未接通。

爆款文案库按账号快照和后台规则自动入库；商品类目、内容类型、开场/表达/结尾、状态、整理稿和备注可编辑，类目和开场可筛选。账号和视频资料及档案对所有登录成员共享，所有登录成员可编辑，也可在详情确认移除共享文案；进行中的处理完成后才能移除，待执行任务取消，历史记录和既有脚本保留，自动入库不会重新加入已移除视频。原始逐字稿与整理稿分开保存，发布文案不能视为逐字稿。

自动入选与提取由每位成员在文案库页面单独设置，默认关闭，只处理本人勾选、未删除的竞对账号；他人看不到也改不了自己以外的设置。开启后按最新账号快照判定：累计播放 ≥70 万，或 ≥1 万且点赞、收藏、评论任一达到已保存阈值。阈值须明确填写大于 0 且不超过 100，留空表示该率不参与判断；5%、0.8%、0.15% 只是试算默认值，不会被自动写成正式规则。缺失指标不是零。

页面使用一个总开关；开启前须明确确认复查会消耗 Apify 额度、转写会下载视频音频。开启同时启用发布后约 2 / 3 天复查与本地转写，关闭同时停用。复查复用现有采集 Actor 的账号 + 日期窗口，因此会按账号和 UTC 发布日期取整日视频，不是单视频查询，同一账号同一日期的多个待复查视频合并为一次运行；每次运行仍受单次最高 2 美元熔断约束，2 天与 3 天两次窗口可能分别计费，实际扣费以 Apify 为准。取消勾选、取消账号选择或关闭自动入选后，尚未提交的排队任务会被取消；已提交的任务不会自动撤销，其费用无法追回。提交结果不明确时只标记待核对，绝不自动重提。

逐字稿使用本机 yt-dlp 下载公开视频音频（限制 150 MB、240 秒、无 Cookie）再交给本机 faster-whisper 识别，只接受规范的数字视频号；识别成功才写入原始逐字稿，并记录生成方式与语言，不覆盖人工整理稿。环境未就绪、视频需登录、已下架、超过限制或未识别出语音时会标记提取失败并给出原因，可在页面重新排队；这属于本地下载和识别失败，不代表视频本身没有口播。公开视频能否下载取决于平台当前策略，不保证每条都能提取。

### Kalodata 密钥设置
