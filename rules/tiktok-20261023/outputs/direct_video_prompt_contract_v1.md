# 直接视频提示词合同 V1

## 默认流程

```text
Creative Matrix
→ Production Package
→ Commerce Beat Sheet
→ TikTok Creator Spoken Script
→ Detailed Video Prompt
```

空间首帧和Storyboard默认跳过。只有用户明确要求时才恢复这两个阶段。

## 参考图职责

- 人物参考图：只锁人物或宠物身份、脸、体型、毛色、发型、穿搭和固定配饰。
- 产品外观参考图：分别锁同一产品展开和收起时的颜色、材质、外轮廓、提手位置和真实形态。
- 产品细节参考图：锁口袋、拉链、扣件、缝线及其所在位置；不能根据局部特写凭空增加功能。
- 上一段尾帧：只锁下一段开场的瞬时产品状态、人物位置、画面方向、环境排列和光线状态；不得覆盖人物或产品Canonical参考。
- 每个Prompt开头必须列出Reference Role Map，直接用 `@图1`、`@图2` 等引用写明人物、产品展开态、收起态和细节图各自锁定的内容。缺少某类图片时直接用文字描述对应对象，不虚构参考图或产品结构。可复制Prompt中不写本地文件名、聊天附件名、上传与绑定说明，也不写关于图片编号的解释。人物图中的背景和产品图中的布景不得转移到视频。

## 无Storyboard时的必写信息

每个视频分段提示词必须独立写清：

1. 场景地点、可操作平面、背景几何和通行方向。
2. 时间、物理光源、光线方向、色温和曝光关系。
3. 人物、产品和所有关键物品的开场位置与状态。
4. 每个镜头的时间、景别、构图、机位高度、摄影机稳定方式和镜头终点。
5. 产品真实使用步骤、双手顺序、受力方向、材料反应和可见结果。
6. 每件物品的来源、移动路径、落点和段末状态。
7. 口播归属、同期声、环境声、停顿和无口播区间。
8. 人物、产品、物品数量、轴线、屏幕方向、光线和服装连续性。
9. 不允许发生的错误，包括产品瞬变、额外手、重复物品、错误提柄、外观漂移和未批准功能。
10. 本段结束画面，以及它怎样成为下一段的剪辑入口。

## 17秒分段与剪辑边界

- 以后默认每段最长17秒，末段按总时长的剩余秒数；例如30秒为17+13秒，45秒为17+17+11秒。每个镜头最长3秒，在口播信息点或动作完成点切换。
- 17秒段末必须落在完整动作后的稳定状态、明确Hard Cut点或Match Cut点；不得把关键接触、提柄、聚拢、打开或关闭动作拆在两段之间。
- 下一段0秒从新的完整镜头开始，不把两个独立生成片段伪装成同一条未中断镜头。
- 同场景跨段时，保持相同时间、主光方向、色温、天气、服装、产品状态和屏幕方向；推荐使用上一段实际尾帧辅助锁定。
- 跨场景时，在17秒边界使用明确Hard Cut，下一段重新建立新地点的物理光源；不得用无动机的光线渐变或空间融化连接地点。
- 上一段尾帧只能在上一段生成并确认后成为正式辅助参考；提前编写的下一段Prompt标记为“待尾帧绑定”。

## 产品Demo

- A类关键Demo必须完整放在单个分段内，优先使用不超过3秒的连续镜头；超过3秒的真实动作拆成相邻镜头时，切点要展示相同的阶段状态，保留动作起点、接触、受力、材料变化和结果。
- Prompt必须写明同一产品、左右手分别接触的位置、同步或先后顺序、力的方向、材料怎样变化以及最终状态。
- 快切可以压缩普通取物和换场，不得压缩证明产品成立所必需的因果过程。
- 产品用途、尺寸、承重、材质和效果只使用Product Ground Truth与Approved Claims。
- 视觉Hook直接从动作开始。例如宠物进垫后主人接上提柄动作，不插入驻足、惊讶、摆姿势或等待镜头。
- 每条脚本至少两次人物正对镜头说话。Prompt指定正面机位、直视镜头、准确台词和同期口型；其余操作镜头可配主人画外口播。

## 多段Prompt交付

- 每段单独提供可复制Prompt和Reference Role Map。
- SEG01可直接生成；SEG02及以后若依赖上一段尾帧，先提供完整待绑定Prompt，实际生成前把已确认尾帧作为指定参考图上传。
- 每段列出开场状态、段末状态、与下一段的剪辑类型以及Continuity Locks。
- Prompt直接引用Beat Sheet ID、revision和hash；Beat变化后创建新Production Version，不覆盖旧Prompt。
