# TikTok 带货镜头节奏合同 V1

## 适用范围

适用于本项目之后所有进入 PRODUCTION_MODE 的 TikTok 带货视频，包括 Commerce Beat Sheet、正式故事板与 Seedance 视频提示词。

本合同只规定镜头节奏和构图选择，不改变 Product Ground Truth、Approved Claims、Demo 顺序、口播内容、Beat 时间或 CTA。

## 默认节奏

- 每个镜头最长3秒；按口播语速、信息点和动作落点切换，通常约2–3秒。开头动作可更短，不能用冗余反应和等待凑时长。
- 17秒视频段通常约6–8个主镜头；实际镜头数由台词和动作决定，全部满足单镜头最长3秒。
- 有效变化必须改变机位高度、观察方向、景别或画面信息中的至少一项，并承担新的销售任务。
- 单纯数字变焦、无信息变化的推拉、同角度重复画面，不计为有效镜头变化。
- A类关键Demo优先在不超过3秒的连续镜头中完成。真实动作需要更久时，按可见动作阶段拆成相邻镜头，切点前后保持手、提手、物品、受力方向和产品状态一致，不跳过关键因果。

## 构图池

| 构图类型 | 默认用途 |
| --- | --- |
| 平视构图 | 人物交流、Hook、结果确认、CTA |
| 俯拍构图 | 产品与手部操作关系 |
| 高机位俯拍 | 容量、整体布局、商品来源与落点 |
| 吊眼构图 | 镜头略高于眼线观察人物与产品；仅在画面含义明确时使用 |
| 鸟瞰式近距离俯拍 | 商品数量、口袋、局部 Demo 证据 |
| 顶视构图 | 完整铺开面积、物品分布、操作顺序 |
| 垂直俯拍 | 产品边界、左右对称动作、收拢路径 |
| 仰拍构图 | 提起产品后的体量、人物行动结果 |
| 超低机位仰拍 | 强化提走动作或产品在前景的体量；避免遮挡脸和 CTA 手势 |
| 腰部机位 | 人物、双手与台面产品同时入镜 |
| 胸口机位 | 对镜口播、朋友视角交流 |
| 膝盖机位 | 行走、提包、离场结果 |
| 地面机位 | 脚步、产品离地、移动方向 |
| 斜俯拍 | 展开、放入、整理等兼顾人物和产品的操作 |
| 斜仰拍 | 产品提起、人物携带、行动出口 |

## 按销售任务选角度

- Hook／人物反应：平视、胸口机位、腰部机位。
- 传统方案与痛点：平视或斜俯拍，同时保留人物与旧方案的空间关系。
- 产品揭示与展开：腰部机位、斜俯拍、高机位俯拍。
- 容量与装入过程：顶视、垂直俯拍、鸟瞰式近距离俯拍、高机位俯拍。
- 细节与口袋：鸟瞰式近距离俯拍或斜俯拍近景。
- 收包关键 Demo：稳定高机位俯拍或垂直俯拍，完整保留双手、两侧提手、产品边界和内部物品。
- 结果确认与离场：平视、腰部机位、膝盖机位、仰拍或斜仰拍。
- CTA：人物脸、产品和手势必须同框，优先平视或胸口机位。
- 每条脚本至少有两次人物正对镜头并同期说话，建议分别在关键利益介绍和结尾CTA；这两次都要看到脸、眼神和口型，背影或画外音不计数。

## 组合规则

- 每个17秒分段尽量使用至少3个不同的构图家族：人物交流、产品操作、结果行动；短尾段按实际时长安排。
- 相邻镜头原则上不连续使用相同机位和相同景别；若用于证明连续操作，必须明确标注“连续 Demo 例外”。
- 镜头切换应跟随新的信息点、动作落点或口播滑梯节点，不在一句话中无目的乱切。
- 产品出现后，镜头优先服务产品展示与 Demo；人物反应镜头不得长期挤占产品画面。
- 所有切换都要保持轴线、屏幕方向、人物身份、产品状态和物品数量连续。

## 生产文件要求

- Commerce Beat Sheet：在 shot_group 中记录建议时长和镜头任务，不因镜头细分改变 Beat 时间。
- Storyboard（仅用户明确要求时）：每格必须写明时间、景别、构图类型、机位高度、动作、结束状态。一个 shot_group 可以拆成多个构图，但不得新增卖点或改写 Demo。
- Detailed Video Prompt（默认）：逐镜头直接继承Beat Sheet和口播的时间、构图、动作与产品状态；关键Demo标注连续动作和禁止跳变，并补齐没有Storyboard时所需的空间和光线信息。
- 故事板只负责空间、动作、时间和构图，不负责承接产品最终外观；产品外观由正式产品参考图锁定。

## 默认交付标准

以后没有额外说明时，按以下标准执行：

1. 每个镜头最长3秒，通常2–3秒，在语义或动作完成处切镜。
2. 45秒视频至少15个主镜头，具体数量随台词和动作增加。
3. 产品介绍与 Demo 占据中段主要画面。
4. 关键Demo优先在3秒内连续完成；如需拆镜，前后动作状态必须匹配。
5. 每个镜头都标注构图类型和销售任务。
6. 每条脚本至少两次人物正对镜头同期说话。
7. 不为了丰富镜头而改变人物身份、口播逻辑、产品事实或操作步骤。
