# TikTok Shop达人账号深度分析工作流

## 一、这套工作流解决什么问题

传统达人筛选主要回答：

- 达人粉丝量够不够

- 受众画像是否匹配

- 播放量和互动率怎么样

- 报价、佣金是否合适

- 是否值得建联寄样

这些信息只能帮助团队决定“优先联系谁”，不能回答：

- 达人稳定能做什么内容

- 用户为什么愿意看他

- 商品能否自然进入账号

- 商品进入后能否被用户记住

- 这位达人适合种草、演示、成交，还是提供广告素材

因此，TikTok达人研究需要分成三层：

1. 数据筛选：判断谁值得继续研究  

2. 账号分析：判断达人适合承担什么内容任务  

3. 商业验证：判断合作后能否产生订单、GMV和可接受的退款结果

公开作品和评论只能支持前两层判断，真实商业价值必须通过店铺合作数据验证。

## 二、开工前先定义研究任务

拿到达人账号后，不要直接开始刷视频。

先填写：

> 本次分析要判断【达人】能否承担【商品】的【内容任务】，商品应以【进入身份】出现，分析结果将交给【使用人】用于【后续决策】。
> 
> 

### TikTok常见内容任务

同一个达人不一定适合所有任务。

例如，娱乐型达人可能适合痛点放大和场景植入，但不一定适合复杂产品讲解；垂类专业达人播放量可能不高，却更适合产品演示、信任证明和异议处理。

## 三、达人研究分四层执行

### 第一层：批量筛选

对象：约100名候选达人。

主要查看：

- 国家和语言

- 粉丝量

- 近期播放中位数

- 互动率

- 受众画像

- 主营类目

- 历史带货情况

- 报价和佣金

交付：候选达人池。

### 第二层：快速账号判断

对象：约20名重点达人。

查看：

- 置顶作品

- 近期10—15条内容

- 商业或挂车内容

- 账号是否正在转型

- 商品是否有自然进入空间

交付：值得深度研究的达人名单。

### 第三层：账号深度研究

对象：约5—10名核心达人。

整理：

- 置顶作品

- 近期30—40条作品

- 高、中、低数据代表作品

- 商业及挂车内容

- 代表作品对应评论

交付：达人稳定母题、用户认知、商品进入方式及合作风险。

### 第四层：商业验证

对象：约3—5名首轮合作达人。

验证：

- 视频发布数量

- 商品点击

- 订单和GMV

- 达人佣金

- 退款和退款GMV

- 素材广告授权

- GMV Max投放表现

交付：继续、迭代、观察或停止合作的决定。

## 四、怎样读一个TikTok达人账号

### 先看置顶作品

置顶代表达人希望用户怎样认识自己。

需要判断：

- 置顶内容与近期内容是否一致

- 达人当前定位是否稳定

- 账号是否正在转型

- 历史爆款能否代表现在

### 不看平均值，看数据分布

至少比较：

- 最低值

- 中位数

- 最高值

- 近期波动

少量爆款会拉高平均播放量，所以合作预期不能按照平均值或最高值设定。

### 找内容母题，不贴大类标签

“家居、户外、美妆、生活方式”只是达人标签，不能直接指导Brief。

真正需要提炼的是达人反复在讲的具体事情，例如：

- 解决令人烦躁的小问题

- 第一次尝试某种产品

- 便宜产品与昂贵产品对比

- 专业人士拆穿常见误区

- 伴侣之间的生活冲突

- 真实环境下的产品测试

- 日常自我管理和效率提升

### 用低数据作品反向验证

如果一个开头、场景或结构在高数据和低数据作品里都大量存在，它可能只是达人习惯，不一定是成功原因。

只有一个做法：

- 在多条高数据作品中反复出现

- 在低数据作品中明显较少

- 不是依赖单次热点或偶发事件

才有资格进入合作测试。

## 五、怎样读评论区

评论必须按作品分别整理，不能把整个账号的评论混成一个总词云。

建议分成八类：

最重要的不是评论总量，而是：

> 品牌希望用户形成的商品认知，到底出现了多少次？
> 
> 

如果一条视频有2000条评论，但绝大多数都在讨论达人伴侣、衣服或者某个玩梗细节，只有几条评论提到商品，那么它可能是优质内容，却不是优质带货内容。

## 六、商品进入判断

商品可以用不同身份进入达人内容：

- 问题解决工具

- 日常习惯的一部分

- 测评对象

- 专业建议中的推荐项

- 剧情冲突的解决方案

- 达人真实体验中的新发现

不是所有商品都适合用“强推荐”方式进入。

## 七、最终交付不能只是“适合/不适合”

一份完整的达人账号分析，最终必须回答：

1. 达人稳定的内容母题是什么  

2. 用户为什么看他、信任他什么  

3. 达人适合与不适合承担什么任务  

4. 商品最自然的进入场景和身份是什么  

5. 必须展示什么产品动作和信任证据  

6. 哪些人物梗或话题可能盖过商品  

7. 首轮合作测试什么变量  

8. 用什么内容与商业指标决定继续或停止
