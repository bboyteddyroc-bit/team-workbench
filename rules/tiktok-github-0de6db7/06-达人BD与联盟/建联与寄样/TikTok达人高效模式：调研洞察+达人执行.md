# TikTok达人高效模式：调研洞察\+达人执行

举例：我们产品，找了几十个达人合作，拿到一百多条达人素材，出单没几个；就连找的几个所谓top达人，一星期也就出四五单，GMV根本跑不起来，怎么办？

首先：别急着怪达人不行，问题的根源其实不在达人身上，而是**在找达人之前，没做好“调研”这件关键的事。**

## **大家眼中的“Top达人”，可能根本不会卖货**

优质达人本来就极少，所谓的top达人到底是怎么定义的？粉丝多？视频好看？还是带货GMV高？

但仔细看，他可能之前发的都是娱乐内容，内容能力一般，根本不会做电商卖货视频。

还有一些达人能带得动货，是因为他们接的品本身就好、人群广、客单价合适，再加上商家预算足，所以一波就爆了。换个品给他，也不一定能卖。

## **达人只是内容执行者，调研只能靠自己的团队**

**达人基本上是不会帮你做调研的。**

**一条视频能不能爆、能不能出单**，**决定权不在达人**

**而在自己的团队——有没有提前调研清楚**

- 产品的核心卖点？

- 要瞄准哪波人群？基础人群（A1\-A5人群 A1：没触达过A2：初次触达过**A3：深入了解过\-点赞\-评论\-分享**A4：下单 A5：复购）

- 同行是怎么卖的？

- 流量渠道有哪些？A卖点——A店铺在做达人了；

- 他们爆单视频的结构是什么？

我们自己不调研，达人也不会替你调研。就导致了达人拍出来的效果乱七八糟，自己也判断不明白，也沟通不明白所谓的脚本和卖点，所以就导致了现在这种凭借着所谓的运气出单；

达人确实还能发视频，但他们不懂人群、不懂卖点、不懂你的产品策略，**他们本质都是内容执行**。

## **现阶段达人合作的最高效模式**

**调研给出的洞察才是灵魂。**

**没有调研，达人拍一百条都是“随机内容”；**

**有调研，你找达人还是找外包机构，成功概率都能大大提高。**

**现阶段找达人最高效的模式就是**：**调研洞察\+达人执行**。

美区达人的内容能力现在普遍还在成长阶段，他们对内容的理解可能跟我们团队现在差不多。

我们不调研，他们就随便拍；我们调研清楚了，他们才能拍得准。

我们做这一切的最终目的，不只是自己能做素材、打开自卖这条渠道，更重要的是能赋能达人和投放渠道，最后把店铺的所有流量渠道都跑稳，实现长效增长。
