# TK带货达人库搭建与合作达人评级方案

**2025/08/27 初版**

## **一、TikTok** **带货达人库搭建**

https://shop\.tiktok\.com/streamer/home?region=us  直播后台登录

### **\(一\)数据收集**

1. **多渠道采集**

通过TikTok官方创作者市场、第三方数据平台、行业论坛 及MCN机构推荐，收集达人基础信息，包括账号名称、粉丝数量、所属领域、联系方式、合作报价等。

2. **带货数据抓取**

利用数据工具，获取达人历史带货视频的播放量、点赞数、评论数、商品链接点击量、订单成交量、销售额等关键数据，分析其带货能力。

### **\(二\)达人库分类与管理**

1\. **分类维度**

按照带货领域\(美妆、服饰、家居等\)、粉丝量级\(超头部、头部、腰部等\)、带货风格\(直播带货、短视频带货\)、地域\(国内、欧美、东南亚等\)进行多维分类，方便快速筛选目标达人。

2\. **信息录入与更新**

建立 Excel 表格或使用CRM  系统作为达人库载体，详细记录达人各项信息，并定期更新数据，确保信息时效性。同时，标注达人合作意向、合作历史等备注信息。

## **二、合作达人评级体系优化**

在原有评级标准基础上，强化带货相关指标，细化评级等级 \(S 、A 、B 、C 、D 、F\),具体如下：

### **\(一\)核心评级指标**

1. **带货能力** \(权重40%\)

- **GMV  \(商品交易总额\)** :统计合作期间达人带货的总销售额，作为衡量带货能力的核心指标。

- **ROI**  **\(投资回报率\)** :计算品牌投入与达人带货收益的比例，反映带货活动的盈利能力。

- **转化率：**统计商品链接点击量与实际订单成交量的转化率，评估达人引导购买的能力 。

2. **内容适配度** \(权重25%\)

- **产品展示效果：** 评估达人带货视频中对产品特点、优势的展示是否清晰，能否有效吸引用户购买。

- **场景贴合度：**判断达人带货场景与产品目标受众的匹配程度，如母婴产品在亲子场景 带货效果更佳。

3. **合作配合度** \(权重15%\)

- **响应速度：**记录达人在沟通合作需求、反馈问题时的响应时间，及时响应能保障合作顺利推进。

- **内容交付及时性：** 评估达人是否按时完成带货内容制作与发布，避免延误推广时机。

4. **粉丝反馈** \(权重10%\)

- **商品好评率：** 统计用户通过达人带货购买商品后的好评比例，反映粉丝对带货产品的认可程度。

- **负面舆情：** 监测粉丝在评论区、社交平台对达人带货行为的负面评价，如虚假宣传、质量问题等。

5. **账号稳定性** \(权重10%\)

- **违规记录：** 查看达人账号是否存在违反 TikTok 平台规则或品牌合作条款的行为。

- **粉丝流失率**：关注合作期间达人粉丝数量的变化，过高的流失率可能影响带货效果。

## **三、达人库与评级管理策略**

### **\(一\)分级合作策略**

1. **S级和A级达人**：建立长期深度合作关系，给予更高的合作报价、专属资源支持\(如优先 选品、定制化推广方案\),共同打造爆款带货活动。

2. **B级达人：** 保持常规合作，定期评估其成长潜力，提供培训与指导，助力提升带货能力。

3. **C级达人：** 减少合作频次，要求其针对短板进行改进，改进后再考虑增加合作机会。

4. **D级和** **F级达人**：暂停合作，将其移出优质达人库，若为F级达人，永久终止合作并列入黑名单。

### **\(二\)动态监控与优化**

1\. **数据追踪：**通过数据平台实时监控合作达人的带货数据、粉丝反馈等，及时发现问题并调整合作策略。

2\. **定期复盘：** 每月对合作达人进行评级更新，每季度对达人库整体运营效果进行复盘，优化评级标准与合作策略。
