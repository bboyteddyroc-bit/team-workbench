# 产品定位六维度

## 核心观点

产品定位不是写卖点，是回答 6 个问题。

卖点成立 ≠ 卖点能转化，中间差的是做内容的顺序和过程。产品定位的深度，直接决定内容打透的精准度。

## 六维度详解

### 维度1：用户定位

**核心问题：卖给谁？脑子里有没有一张具体的脸？**

- 不是写"25\-35岁女性"这种人口统计学口径

- 而是回答：用户是谁？年龄区间？职业或生活状态？她为什么需要这个产品？在意什么？排斥什么？

**自测方法**：把 Listing、产品图片、卖点投喂给 AI，让它分析能否得出一个精准用户画像和具象化场景

### 维度2：场景定位

**核心问题：在哪用？做什么动作？用多久？**

- 场景定位决定产品结构、材质选型

- 不要只说"日常使用"，要拆成：早晨出门/开车通勤/办公室/午休/开会/下班回家

**结构决定公式**：

- 动作决定结构

- 时长决定面料

- 接触决定细节

**反面教材**：用长得很像医疗器械的产品，去打高端职业女性的办公场景

### 维度3：卖点定位

**核心问题：发力点在哪？哪个点做到120分能让人记住？**

- 不是把所有优点都罗列出来

- **选择一个感知锚点，围绕它做120分**

- 用户记住的永远不是面面俱到，而是某一个"不一样"

### 维度4：价格定位

**核心问题：用户觉得"值"多少，而不是"成本\+利润"**

|定价逻辑|说明|
|---|---|
|竞品比价|被算法拿捏，永远陷入价格战|
|价值感知定价|用户判断"这个产品值不值"，支撑高客单价|

**高客单价支撑点**：面料触感/结构设计/细节耐用/体验舒适/视觉高级/包装高档

### 维度5：风格定位

**核心问题：视觉语言是否符合目标用户审美？**

- 不是自己喜欢什么，也不是工厂有什么现料颜色

- 而是代入用户视角，做符合目标用户审美的风格

- 同质化严重的类目里，风格本身就是差异化

### 维度6：竞争定位

**核心问题：我们比竞品强在哪里？**

- 不能简单说"质量更好"——所有卖家都会这么说，用户无法判断

- 有效的竞争定位：找到用户在意但对手没做好的维度，在可感知的差异上做到极致

**案例**：竞品强调"支撑强"，差评分析发现用户真正抱怨"戴久了卷边" → 竞争定位改为"戴一天不卷边"，开发方向随之清晰
