# TK\-运营\-选品必看

## 自评分标准

### 一、前言

在 TikTok Shop 的运营过程中，选品始终是驱动生意增长的核心环节。一个商品能否跑出爆款，不仅取决于平台的流量扶持和运营策略，更关键的是商品本身是否具备内容传播价值、供应链承接能力以及市场竞争力。

为帮助团队在选品环节实现标准化、量化和可复制，本标准提供一套简明清晰的自评分模型，便于快速筛选潜力商品。

### 二、目的

通过对候选商品进行多维度量化打分（满分 **100**分），团队能够：

1. 建立统一的选品标准，减少主观判断带来的偏差。

2. 提前识别具备爆款潜力的商品，集中资源进行孵化。

3. 避免因供应链不足、内容不适配或价格力不足导致的试错成本。

4. 提升选品效率，使商品决策更具数据化和可执行性。

最终目标是：**确保进入运营环节的商品均为“优中选优”，为爆品增长奠定基础。**

# 三、评分模型

### 四、判定标准

- **≥80分 → 好选品**（优先投入资源，具备爆品潜力）

- **60\-70 分 → 待观察**（可小规模测试，重点验证内容适配度和市场反馈）

- **≤59 分 → 不适合**（暂不投入资源，建议放弃或替换）

### 五、应用方式

1. 在进行选品前，由运营、供应链联合完成自评分。

2. 分数计算完成后，按照判定标准决定是否进入测试环节。

3. 对“待观察”商品，可进入小规模投放或达人试拍环节，进一步验证。

4. 每月进行复盘，更新评分标准与实际表现的匹配度，持续优化模型。

**缺一个评分详细表（一起做）表头： 竞对站内价格，链接，竞对站外价格，链接，竞对做的卖点（已验证）分析出还未打透的卖点和方向人群。备货周期表，素材优化方向。测品方式，结论。等。**

**备货前 一定要把评价做上。**

# 第一步 运营要“懂”产品 

### 测品怎么测，测哪些

**1、测卖点。**一个产品3 \~ 5个卖点，哪个卖点是最好打但同行没有打过的？（做好分析和对应的文档同步至所有同学）

**2、测人群。**哪些人群会消费？他们当下的痛点和潜在需求是什么？（运营要懂产品，固定好卖点对应的人群，这样剪辑和拍摄才知道往哪个方向去做）

**3、****测内容模板****。哪套模板能把产品和人群有效地连接起来？**（需要按照下面的举例进行测试，最终得出结论）

**4、****测原生感****。灯光、节奏、置景这些细节能否促进老外下单**？（拍摄剪辑根据运营做出的分析文档，分析对应人群所喜爱的布景 ，灯光和视频配色）

### 爆款视频模板\(可添加,要总结方法论）

**核心点：撬动老外的注意力**

#### 1\.视觉锤——强效果对比

适用**家用清洁**和**3C产品**

可以弱化需要达人浮夸“表情”的种草优势，用炸裂效果就可以种草和留住老外。

唯一要研究的就是，你的产品要怎么做出，“**极端好”对比“极端差”的效果**

#### 2\.高性价比模版——“捡漏的爽感”

比如下面这三种开头，就是**老外那边最地道的表达**，轻松抓住他们的注意力：

- 不知道是TikTok搞错了价格还是怎么样，兄弟姐妹们快冲！

- 别再花这么多钱买某某产品（某大牌）了，TikTok终于把价格打下来了！

- 我都不知道他们怎么赚钱的，怎么会这么便宜？

**核心技巧：**

- 价格对比要明显，比如原价$50 vs 现价$9\.9。

- 语气/风格最好像KOC分享推荐好物的口吻，增强信任感。

#### 3\.沉浸式ASMR——解压又带货

不用露脸、不用说话，单靠产品使用时的声音和画面，就能**让老外在不经意间被种草下单**。

比如清洁刷的使用场景：镜头对准布满污渍的缝隙，刷子来回擦拭的“沙沙声”、污渍被带走的“滋滋声”，搭配逐渐变干净的画面，既解压又治愈。老外看着看着，就会不自觉代入 ——“我家好像也有这问题，这刷子好像真能解决”，种草就在不知不觉中完成了。

不单单是**产品使用**，**沉浸式开箱、测评**等，都是流量密码。一边用解压的声音让老外上头，一边在无形中展示产品真实的效果，流量和转化率都很容易提升。

**这三种操作门槛低**、**裂变能力强**，还完美**避开了“出镜难”的问题**

# 第三步 产品素材迭代

# 第四步 测品数据量化标准

初期选品通过评分表，综合评分80分以上验证没问题备货，先跑素材种草，收集评论区反馈。到货后，挂车收割。

**素材点击率超过大盘均值5%以上—启动海外仓备货—首批发300\-500件**

**如果素材点击率连续三天低于均值的15%—需要换品**

#### 测品成功 有三条标准：

1. **持续出单，素材内容可复制化，产品卖点受众广。**

2. **自然流出单，日均单量＞5单 ，转化率1%\-3%左右**

3. **持续一周广告出单日均单量＞15单 ，ROAS 接近保本 **

点击率（CTR）合格线参考： 

- 基础⻔槛：≥2%（⾏业均值） 

- 优秀⽔平：3%\-5%（如冲突对⽐主图或痛点前置视频） 

品类差异： 

- ⾼客单价 / 功能型产品（如 3C、家居）：1\.5%\-2\.5% 

- 冲动型消费产品（如新奇玩具、快消品）：需≥3% 

关键： 

CTR＜1\.8%：⽴即更换主图 / 视频，优先测试「前后对⽐图」或「使⽤场景动图」 

CTR＞3% 但转化低：检查详情页逻辑，需强化「价格锚点 \+ 售后保障」

⼴告 CTR vs ⾃然 CTR：⼴告 CTR 通常⽐⾃然流⾼ 0\.5%\-1%，若⾃然 CTR 过低，需优化标题关键词匹配度 

#### 视频 3 秒留存率：算法推荐的核心门槛

合格线参考： 

- 基础流量池（0\-1 万播放）：≥65%（决定是否进⼊下⼀流量池） 

- 进阶流量池（1\-10 万播放）：≥50%（需配合评论互动率＞8%） 

- 冷启动期容忍值：≥45%（新素材可放宽标准） 

- **3 秒留存率＜40% 的素材需⽴即淘汰，避免拉低账号权重  ** 

#### 出单情况：出单数据标准  自然流出单

**⾃然流出单标准 **

冷启动期（0\-3 天）：⽇均单量≥3 单

稳定期（7 天以上）：⽇均单量≥5 单，且⾃然流占⽐＞30%（避免纯⼴告驱动） 

潜⼒爆品信号：⾃然流⽇均单量＞10 单 \+ 退货率＜15%（具体看品类）\+** 搜索量环⽐增⻓＞20% **

**广告流出单标准 **

- 冷启动期（0\-3 天）：⽇均单量≥5 单，ROAS≥1\.2（保本线） 

- 扩量期（5 天以上）：⽇均单量≥15 单，ROAS≥2\.5（可规模化） 

- 预警：若⼴告出单占⽐＞70%，需⽴即优化⾃然流量策略  

- 转化率（CVR）：点击 \- 购买转化率≥1\.5% 为合格，2%\-3% 为优秀（高客单1%） 

- 加购率：加购量 / 曝光量≥5%，若＜3% 需优化详情⻚「限时赠品」或「价格对⽐」

- 售后率：＜20% 为健康⽔平，＞25% 需排查产品质量或详情⻚描述问题（具体品类具体分析）
