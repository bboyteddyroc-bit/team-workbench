# TK\-投放\-GMX里的成交人群洼地：5种挖法

核心：

GMV MAX的素材，本质是在帮系统找到新的成交人群样本。

所以“人群洼地”的意义，就是：

找到系统还没被大量训练过的成交人群。

很多人做素材时，习惯先想：

- 怎么做钩子

- 怎么写脚本

- 怎么做剧情

但在 GMV MAX 里，一个更关键的问题其实是：

这条素材在训练系统找哪一类成交人群？

如果所有素材都在找同一类人，计划一定越来越难跑。

所以真正的突破口其实是：不断找到新的成交人群洼地。

# **第一种：场景切人群**

这是最简单，也是最容易跑出来的方式。

很多产品其实不是只有一个使用场景，而是有很多。

例如一件衣服。

大多数素材都会讲：

- 日常通勤

- 显瘦百搭

但如果换一个场景，人群就会完全不同：

- 相亲穿搭

- 见家长穿搭

- 旅行拍照穿搭

- 约会穿搭

表面看是内容变化。

但在 GMV MAX 里，其实是在做一件事：

给系统提供新的成交场景样本。

这往往能打开新的流量。

# **第二种：身份切人群**

很多产品其实可以服务不同身份的人。

但素材往往只讲一种。

例如一条裤子。

大多数素材会讲：

- 小个子女生

但其实可以切很多身份：

- 职场新人

- 宝妈

- 大学生

- 微胖女生

当素材开头直接点出身份时：

系统会优先去找 有类似行为标签的人群。

这也是 GMV MAX 非常典型的人群训练方式。

# **第三种：情绪切人群**

很多成交其实不是因为功能，而是因为情绪。

例如：

一件显瘦的衣服。

可以讲：

功能逻辑：

- 显瘦

- 百搭

也可以讲情绪逻辑：

- 不敢拍照的人

- 穿衣服总没自信的人

- 总被朋友说胖的人

这类素材往往会吸引另一类情绪驱动人群。

而这些人群很多时候是竞争较少的流量池。

# **第四种：时间切人群**

很多人忽略一个很重要的变量：

时间节点。

例如：

同一件衣服。

可以在不同时间节点打不同人群。

国内例如：

- 春节相亲

- 五一出游

- 开学穿搭

- 年会穿搭

当素材明确一个时间节点时，

系统会更容易匹配 正在发生该行为的人群。

这类素材往往会在节点期突然爆量。

# **第五种：消费阶段切人群**

很多素材默认用户已经准备买。

但实际上用户的消费阶段是不同的。

例如同一款产品，可以打：

刚意识到问题的人

例如：

“原来很多人裤子显胖是因为版型错了”

已经在对比的人

例如：

“普通牛仔裤 vs 显瘦版型牛仔裤”

准备下单的人

例如：

“今年最容易断货的一条显瘦裤”

不同阶段，其实是不同的成交人群。

而 GMV MAX 很依赖这种 行为分层信号。

很多人觉得：

素材越来越难做，是因为创意枯竭。

但在 GMV MAX 里，更真实的一句话其实是：

不是创意不够，而是成交人群被打透了。

当所有素材都在抢同一批成交用户时：

- 点击会越来越贵

- ROI会越来越难稳定

- 素材生命周期越来越短

所以未来素材竞争真正的核心，很可能不是：

谁的创意更花哨。

而是：

谁能更快找到新的成交人群。
