# TikTok GMV Max 新素材消耗问题分析与优化

## 核心问题

- 新上传素材几乎不消耗 

- 老素材消耗减缓甚至下降 

- 换脚本或重新拍摄老素材，结果仍不理想 

- 根本原因：**素材同质化 \+ 人群覆盖窄**

## 一、人群未拓宽：新老素材互相内卷

### 现象

- 不同脚本素材，本质仍打同一类人群 

- 换说法或镜头无法扩大触达 

- 同一批用户被反复触达 → 转化下降 → 系统难以继续放量 



### 分析

- 产品通常有多类潜在人群 

- 缺乏系统调研 → 内容停留在单一人群 

- 系统基于数据分发 → 只能往已有验证人群放量 

### 建议

- 对现有素材进行人群拆解：哪类人被触达？ 

- 调研潜在人群 → 扩展素材覆盖范围 

- 避免单一人群内卷，提高流量多样性 

## 二、脚本结构未变化：系统不认作新内容

### 现象

- 新素材仅换镜头或文案，本质脚本逻辑未变 

- 系统判断内容是否“新” → 新素材与老素材结构接近 → 抢同一波流量 

- 结果：老素材仍能跑，新素材几乎无法起量 

### 分析

- TikTok GMV Max系统更看重内容差异化而非表面变化 

- 差异化最重要的部分是**开头设计**

### 建议

- 拆解老素材，找出核心逻辑和开头筛人方式 

- 新素材需在开头逻辑或人群筛选上形成差异 

- 不仅仅换文案或镜头，要改变内容表达方式 

## 三、开头设计不会筛人

### 现象

- 开头普遍面向所有人，缺乏精准筛人 

- 播放量可能正常，但转化不稳定，放量有限 

### 分析

- TikTok系统分发依赖行为数据 

- 开头筛人 → 精准吸引目标用户 → 提升停留率和完播率 → 提高转化 

### 优化策略

- 开头针对目标人群设计，明确筛人 

- 贴近老外日常表达：语言、话题、语气符合习惯 

- 避免直接使用国内短视频套路（悬念、强冲突、拉踩等） 

- 调研近期老外热议话题，结合产品卖点优化开头 

## 四、解决方案：从拆解到差异化

### 核心思路

1. **拆解现有素材**

    - 拆人群：目标触达的用户类型 

    - 拆开头：筛人的方式和表达逻辑 

    - 拆表达：镜头、文案、节奏差异 

2. **基于拆解扩展**

    - 换目标人群或细分人群 

    - 改开头逻辑或表达方式 

    - 在同一卖点下尝试不同表达方式 

3. **关键原则**

    - TikTok GMV Max依赖素材差异化进行分发 

    - 新素材必须在**人群、开头和表达方式上形成差异**

    - 简单改文案或换镜头无法有效起量 

## 五、总结

- **问题本质**： 

    1. 人群重合 → 新老素材互相内卷 

    2. 脚本结构和表达同质 → 系统不认作新内容 

    3. 开头不会筛人 → 无法稳定放量 

- **优化方向**： 

    - 拆解现有素材 → 明确人群、开头、表达方式差异 

    - 扩展人群和差异化开头 → 提升新素材消耗能力 

    - 保证每条新素材都能覆盖不同用户或表达方式 → 系统才会推 

- **核心结论**： 

    - TikTok GMV Max 只有素材有足够差异化，新素材才有机会被系统推起来 

    - 优化重点不是数量，而是**差异化策略 \+ 精准人群筛选 \+ 开头创新**
