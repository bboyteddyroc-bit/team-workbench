# 广告设置流程 \& 预警点

## **一、每日广告例行检查（时间版）——北京时间**

# **二、GMV Max 设置流程（细化版）**

### **第一步：选素材（核心）**

要求：

1. 过去48小时自然流量播放 \>5k

2. CTR ≥ 2%

3. 3秒完播≥20%

4. 评论区无负面反馈

5. 产品评论 ≥4\.5 星

只要不满足以上任意一项 ：不允许加热！

### **第二步：加热规则**

**什么时候能加热？**
 满足以下全部条件：

- 已消耗 ≥ $10

- CTR ≥ 1\.5%

- 转化率 ≥ 1\.5%

- ROAS ≥ 0\.8

**加热方式：**

- 预算拉升 20–30% 不可超过 50%

- 每 2 小时查看一次表现

- 3小时内无明显提升：拉回原预算

# **三、广告预警点（出现就必须处理）**

### **一级预警（立刻处理）**

1. **ROAS \< 0\.5（连续2小时：**立即降低预算或停投

2. **点击成本 \>$1\.5（美区）：**素材问题，停素材

3. **CTR \< 1%** ：换新素材

4. **曝光不动/不消耗** ：素材同质化，重新做开头

### **二级预警（当天内优化）**

1. GMV 不增长但曝光上升

2. 素材播放卡在 500–2000 不突破

3. 评论区负面上升

4. 转化 \>2% 但 ROAS 低 :价格问题

# **四、投放与内容联动机制（让投放不崩）**

### **内容团队必须做到：**

1. 每日交付 **固定条新素材**

2. 每周必须产出 **3 个不同内容框架**

3. 所有素材必须带 **首屏爆点**（前3秒）

4. 所有素材必须保持 **多视角、多场景、多模型用户**

### **投放团队必须做到：**

1. 每天测试新素材

2. 每周至少跑通一个新品类或新内容模板

3. 维护一个“每周表现最强 Top 10” 素材池
