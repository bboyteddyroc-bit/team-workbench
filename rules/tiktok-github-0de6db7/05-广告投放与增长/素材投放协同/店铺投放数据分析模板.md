# 店铺投放数据分析模板

**近7天投放分析：（填写数据时候，按标题1\.2\.3\.4顺序填写，其余自动算出）**

**核心数据指标**

GPM=CTR\(目标页面\)\*付费率\(商店\)\*平均订单价值\(商店\)\*1000

视频每千次播放产生的销售额

观测该条视频的投放效率

ROAS

ROAS=GPM/CPM中

视频的GPM高，不一定带来更高的ROAS;还需要考虑该条视频的流量成本\(CPM\)

**我的ROAS波动与流量成本有关还是投流效率有关?**

放一个例子:先看CPMvsGPM的周期性对比中

会用到三个公式:平均数\(AVERAGE\)，波动方差\(STDEV\)，相关系数\(CORREL\)

- 平均数:观测哪些周期的数值严重偏离平均值

- 相关系数:观测CPM/GPM哪一个数值对ROAS影响更大，辨别是流量成本问题还是投流效率问题（**CPM高是流量成本高，GPM低是投流效率低**）

- 波动方差:哪个数值波动的差值更加大

**我的投流效率波动出现在哪？ **

- 将GPM的数值细拆GPM=CTR\(目标页面\)\*付费率\(商店\)\*平均订单价值\(商店\)\*1000

- 带⽤同样的公式，观测哪⼀个数据影响最⼤ROAS=GPM/CPM中,视频的GPM高，不一定带来更高的ROAS;还需要考虑该条视频的流量成本\(CPM\)

### 总结

- **问题点**：投流效率低，而不是流量成本高。

- **核心原因**：CTR 太低 —素材吸引力不足，点击率拉低了 GPM，从而影响ROAS。

- **次要问题**：CVR 可以优化，但影响小于 CTR；AOV 表现稳定。

- **改进方向**：

    1. **优化素材前 3 秒** → 更强的卖点直接呈现、场景冲击、解决痛点。

    2. **AB 测 CTR** → 同一个商品，多角度/封面/标题测试，快速找出能提高点击的“关键点”。

    3. **投放拆组** → 高 CTR 素材单独跑，剔除低 CTR 素材，减少整体拖累。
