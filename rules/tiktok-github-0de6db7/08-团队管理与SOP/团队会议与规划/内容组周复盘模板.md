# 内容组周复盘模板

## 使用目的

用于内容组与各产品运营每周共同复盘：基于一批素材发布后 7 天的自然流累计结果，判断内容方向是否出现有效信号、问题发生在内容端还是商品承接端，并明确下一批只调整什么。

内容组负责多个产品；每个产品分别绑定对应的运营 Owner。复盘单位是一批素材，而非单条视频。

## 使用规则

- 数据仅统计自然流；每批素材从首条发布起观察 7 天。
- 有历史数据的产品，与上一批同产品、同阶段内容的累计结果比较。
- 首次做某个产品或内容方向时，标记为“首次建立基准”，不仓促判定有效或无效。
- 内容推进顺序：Hook → 卖点 → 人群/场景 → 内容模板。
- 每批只改变一个关键变量；其他关键内容必须记录并尽量保持一致。
- 数据不好时，先定位内容端还是商品承接端的问题；运营与内容共同确认后再进入下一批。
- 个人工作量按“周初确认的日目标 × 实际出勤天数”计算；验收完成即发布，周内不倒改目标。

## 本周总结

| 总结项 | 本周结论 |
|---|---|
| 本周新内容进展 | 围绕__个产品推进了__个内容方向；其中__产品的__方向出现有效信号。 |
| 本周新沉淀的内容标准 | 已确认：__类 Hook 更能留住__人群；__卖点/场景更容易带来点击或成交。 |
| 当前主要问题 | __产品目前卡在__；初步判断为 Hook / 卖点 / 人群场景 / 表达方式 / 商品承接问题。 |
| 团队执行情况 | 本周应发布__条，实际发布__条；影响产出的主要原因是__。 |
| 下周重点 | 继续放大__；只调整__；运营与内容共同确认__。 |
