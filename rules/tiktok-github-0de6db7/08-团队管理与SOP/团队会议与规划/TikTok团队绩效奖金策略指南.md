# TikTok团队绩效奖金策略指南

## 核心观点

- **错误做法**：按 GMV 或利润发奖金。 

- **问题**： 

    - GMV 高不代表团队能力，可能是红利或资源优势。 

    - 利润高未必来自团队贡献，而可能依赖供应链或资金。 

- **正确做法**：绩效奖金应 **奖励能力升级**，而非短期结果。 

- **适用对象**：拍剪编一体团队，可覆盖拍摄、剪辑、编导全链路能力考核。 

## 一、GMV和利润都是伪指标

### GMV 高的误区

- 阶段红利：玩法窗口期、平台政策宽松、品类走红 

- 团队可能只是蹭到流量，而非能力提升 

### 利润高的误区

- 可能依赖供应链优势、资金支持或资源加持 

- 一旦市场环境变化，利润难以持续 

## 二、按短期结果发奖金的风险

- **结果导向奖金** → 团队只追短期数据，不追能力成长 

- 平台政策、内容要求或竞品变化后，团队跟不上 

- **案例**：混剪团队转原创后表现下降，或遇到内容瓶颈 

**核心原因**：团队成长跟不上，奖金制度未驱动能力升级

## 三、绩效奖金应奖励能力升级

### 制定绩效标准

- **绩效标准** = 团队成长路径 

- 目标：提升能力，确保长期可持续内容产出 

- 考核覆盖三个维度：拍摄、剪辑、编导

## 四、绩效奖金/提成方案设计

### 基础工资 \+ 能力晋升奖金

- **基础工资**：保障稳定收入 

- **能力晋升奖金**： 

    - 每季度评估能力指标 

    - 奖金按“能力得分 × 权重系数” 

    - 权重示例：拍摄 30%，剪辑 30%，编导 40% 

### 产出质量激励

- 高质量视频奖励，按评分或留存转化指标 

- 确保质量优先，避免单纯按数量奖励 

### 团队协作加分

- 按任务分工顺畅度、完成周期、创意贡献评分 

### 红利分成（可选）

- 团队整体产出带来GMV/利润时，可按比例分红 

- 分红前提：能力考核标准达标 

## 五、考核周期与执行

1. **考核周期**

    - 每周：产出数量 \+ 初步质量反馈 

    - 每月：能力评分 \+ 视频质量评分 

    - 每季度：晋升与奖金结算 

2. **执行方法**

    - 视频拆片分析：开头留人、置景、剪辑节奏、卖点衔接 

    - 量化评分标准，避免主观偏差 

    - 数据指标验证能力成长：播放量、留存率、转化率 

## 六、奖励能力的好处

- 团队持续成长 → 适应平台变化 

- 结果可持续 → 红利过后仍能保持GMV和利润 

- 避免蹭红利 → 人效稳定 

## 七、总结

- **不按 GMV 或利润发奖金**

- **建立绩效标准，奖励能力升级**

- **逼团队成长，确保内容能力提升**

- **持续结果来源于能力，而非阶段红利**
