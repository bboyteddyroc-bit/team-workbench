# 短视频新手拍摄剪辑快速上手Checklist

## 一、前期准备：拍前必做（√ 完成一项打勾）

### （一）内容与卖点确认

* [ ] 明确核心产品/主题（1个核心，不贪多）

* [ ] 提炼3\-4个核心卖点（按“痛点→功能→场景”排序）

* [ ] 把卖点口语化（比如“20m/s风速”→“1分钟吹干头发”）

* [ ] 选定内容结构（直接套用：困境\+问题\+方法\+结果/痛点\+解决\+场景）

* [ ] 写好文案脚本（每句话≤10字，分镜头对应文案）

### （二）设备与环境准备

* [ ] 拍摄设备（手机即可，打开“高清模式”1080P）

* [ ] 稳定工具（三脚架/手持支架，避免画面晃动）

* [ ] 光线准备（自然光优先，逆光拍轮廓、顺光拍全貌）

* [ ] 背景布置（简洁不杂乱，产品与背景颜色对比明显）

* [ ] 道具准备（搭配产品的辅助道具，比如拍口红配化妆镜）

### （三）拍摄参数设置

* [ ] 分辨率：1080P（新手够用，避免4K占内存）

* [ ] 帧率：30帧/秒（常规），慢镜头拍60帧/秒

* [ ] 比例：竖屏9:16（短视频主流）/横屏16:9（知识类）

* [ ] 关闭美颜（后期按需调，避免前期失真）

* [ ] 打开网格线（辅助构图，选“井”字格）

## 二、拍摄执行：现场操作（√ 完成一项打勾）

### （一）构图与景别

* [ ] 用基础构图（中心构图/三分线构图，新手不踩雷）

* [ ] 拍摄3类核心景别（全景→展示环境/全貌；中景→展示动作/功能；特写→突出细节/卖点）

* [ ] 景别衔接（相邻景别为主，避免跳跃太大）

* [ ] 角度选择（平拍显自然、仰拍显大气、俯拍显全貌）

### （二）运镜与动作

* [ ] 核心运镜（固定镜头为主，搭配1\-2种简单运镜：推/拉/跟）

* [ ] 动作设计（干净利落，同一动作拍2\-3条备用）

* [ ] 避免盲目运镜（产品静置时用固定镜头，移动时用跟随镜头）

* [ ] 关键镜头（卖点细节拍慢镜，同场景3个角度）

### （三）光线与色彩

* [ ] 避免逆光过曝（逆光拍时给产品补光，用反光板/白纸）

* [ ] 色彩统一（同一视频色调一致，美食暖光、数码冷光）

* [ ] 突出产品（产品颜色与背景对比，比如红产品配白背景）

* [ ] 拍摄时长（单个镜头1\-3秒，总素材时长≥成品2倍）

### （四）声音录制

* [ ] 环境安静（关闭风扇/空调杂音，远离嘈杂区域）

* [ ] 录音清晰（配音离手机麦克风30cm，避免喷麦）

* [ ] 录制同期音（产品使用声，比如开盖声/按键声，后期增强代入感）

* [ ] 备用音效（提前录/收藏关键音效：拆箱声/强调声）

## 三、后期剪辑：一步步操作（√ 完成一项打勾）

### （一）素材整理

* [ ] 新建文件夹（分类：原素材/音频/字幕/成片）

* [ ] 筛选素材（删掉模糊/晃动/无用镜头，保留优质素材）

* [ ] 按脚本排序（按“开头→中间→结尾”逻辑排列素材）

* [ ] 标记重点（给卖点镜头/关键音效做标记，方便查找）

### （二）基础剪辑

* [ ] 导入素材（打开剪辑软件，新建项目，设置比例/分辨率）

* [ ] 裁剪时长（每个镜头1\-3秒，总时长控制在15\-60秒）

* [ ] 衔接画面（用淡入淡出转场，避免花哨特效）

* [ ] 对齐声音（配音/音效与画面同步，卡点BGM重音）

### （三）细节优化

* [ ] 加字幕（字体清晰，颜色与背景区分，字号≥24号）

* [ ] 配BGM（匹配产品调性，音量≤配音的50%，不盖过人声）

* [ ] 加音效（关键卖点\+动作音效，比如开盖声/强调声）

* [ ] 加花字（突出核心信息，比如“3秒速热”“买一送一”）

### （四）调色与包装

* [ ] 色彩还原（调亮度/对比度，让画面不灰蒙蒙）

* [ ] 简单风格化（美食调暖、数码调冷，用预设/LUT快速出效果）

* [ ] 加logo/贴纸（位置不挡产品，大小适中）

* [ ] 统一格式（导出MP4，分辨率1080P，帧率30帧）

## 四、导出与审核：最终检查（√ 完成一项打勾）

* [ ] 完整预览（从头到尾看1遍，检查画面/声音/字幕是否同步）

* [ ] 节奏检查（不拖沓、不跳帧，卖点清晰）

* [ ] 细节纠错（错别字/字幕错位/音效突兀，及时修改）

* [ ] 导出设置（确认格式/分辨率，开始导出）

* [ ] 备份素材（原素材\+工程文件\+成片，避免丢失）

* [ ] 发布准备（按平台要求裁剪封面，封面突出产品\+核心卖点）
