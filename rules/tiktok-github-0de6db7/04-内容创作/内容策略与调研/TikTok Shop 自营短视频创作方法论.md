# TikTok Shop 自营短视频创作方法论

**一句话原则：**好内容在电商终端只有一个判断标准——能卖货就是好内容，卖不出去就是垃圾。

# 一、核心原则

做自营短视频的核心要义是**卖点分级**，不是写脚本。

**脚本分析无意义：**脚本分析多为后验性，分析得好不等于能复制爆款。爆款老黑推销视频难以分析出脚本，但就是能卖货。

**三个结论：**

- 电商内容好坏判断标准只有一个：能否卖货

- 脚本分析是后验的，分析好≠能卖货

- 核心是卖点分级，2\-3人可支撑全店原创素材产出

# 二、卖点分级方法

将产品所有卖点分为三个等级，卖点之间要承上启下（对每个卖点进行阐释和继承）。

|等级|定义|作用|
|---|---|---|
|**S级**|人无我有|差异化核心卖点，第一眼冲击力|
|**A级**|人有我优|竞争优势，持续跟进阐释|
|**B级**|人人都有|基础保障，解决用户顾虑|

**关键规则：**卖点必须承上启下，即A级卖点要承接S级卖点进行阐释，B级卖点要承接A级进行补充完善。

## 案例：以挂烫机为例

|卖点级别|卖点内容|说明|
|---|---|---|
|**S级**|体积小|差异化核心，可从包里/抽屉拿出展示|
|**S级**|外观像戴森|人无我有，提升产品溢价感|
|**S级**|熨得平|核心功能，验证产品力|
|**A级**|功率强|人有我优，展示喷气效果|
|**B级**|安全认证 / 价格合理|解决用户顾虑，3C标识展示|

# 三、脚本框架

脚本核心是提供**3个递进理由**说服用户购买，逻辑层层递进。

**说服逻辑模板：**

① 简单介绍产品 → 引出S级卖点 → 提供购买理由

② 针对S级进行深入，补充A级卖点 → 增强购买信心

③ 解决B级顾虑（安全/价格/售后）→ 提供最终行动理由（如免费课程/赠品/一年售后保障）

## 案例脚本：以挂烫机体积小为例

- **引出S级：**"这个熨斗只有巴掌大小，随便塞进抽屉就行"

- **跟进A级：**"别看它小，功率可一点都不差，喷出来蒸气特别足"

- **消除B级顾虑：**"有3C认证，用着安全放心；价格也不贵，性价比很高"

# 四、画面配置原则

不同级别卖点匹配不同画面呈现方式：

|卖点级别|画面配置|示例|
|---|---|---|
|**S级**|强冲击画面，视觉张力|体积小：从包里/抽屉抽出；熨得平：衣物平整前后对比|
|**A级**|功能演示，场景代入|功率强：喷气特写；功率大：快速熨平动态|
|**B级**|信任背书，证据展示|安全：拍摄3C标识；价格：标注到手价|

# 五、操作 Checklist

* [ ] 将产品卖点按S/A/B三级分类整理

* [ ] 确认S级卖点承上启下逻辑成立

* [ ] 为每个S级卖点设计强冲击画面

* [ ] 为每个A级卖点设计功能演示场景

* [ ] 为每个B级卖点准备信任背书素材（3C/价格等）

* [ ] 编写3个递进理由的说服脚本

* [ ] 2\-3人分工执行拍摄（不依赖AI日常内容）

* [ ] 通过4个渠道号分别测试不同卖点方向
