# 解决问题思路 

### 一、账号问题

检查测试方向:IP 、内网 、手机设备

#### 出现的情况:

1、播放量一直在几十；
2、发了5个视频都是0播；

3、账号播放量一直200上下；

#### 测试方法：

1、先对比不同IP下的账号的播放量情况，如果别的IP高，说明可能IP有问题；

2、同1个账号，更换新的IP 网络 手机设备进行测试，观察播放量情况；

## 二、视频质量问题

检查测试方向：查重、视频整体质量不吸引人

#### 出现的情况

1、播放量一直在200多

2、播放量在500\-2000，但是几十个视频没有过10K的

#### 测试方法：

播放量一直200多

1、先确定不是账号问题

2、同1账号发原创且非常有展现力的视频测试播放能否突破200



播放量500以上，但是不爆

1、提升视频质量，开头吸引人，视频框架清晰，镜头展现力强，口播引起话题，（看进阶）

## 三、挂车问题

测试同一账号 同一产品 同一脚本，发布挂车和不挂车的视频，观察播放量情况；

## 四、自我创新

爆品\+爆款视频脚本\+原生感\+吸睛文案（价格比较或者新人价引流）



如何去优化:

首先要分析到位爆款视频的爆点在哪里？

从 视频画面  脚本  声音  文案 等方案去分析优点

#### 方法1

在他原来的脚本上优化，可以将其中爆款视频的优点继续放大，缺点想办法去弥补，做到从展现力 流畅度都要比原视频好；

#### 方法2

举一反三

爆款脚本可以应用在不同的产品上

爆款文案可以应用在不同产品视频上

爆款口播也可以应用在相似的产品上

#### 终极打法

一条视频变量非常多，该怎么做？

就是将每个环节的优点和爆点组合起来，一个视频的爆点越多，爆的概率就越大

# 如何才能爆视频？？

一个爆款视频一定是有非常多的细节在里面；叠加多个爆点的；

爆点从哪里来的？从其他的爆款视频里总结出来的；

爆点，细节，升级优化；才能得出来更好的视频

# 视频内容的四个阶段

1 完全抄袭别人

2\.综合多个爆款视频的爆点

3\.综合爆点转成自己的风格

4 \.升级创造全新爆点
