# 内容复盘

# 问题一：这条视频，明确是“卖给谁”的？

不是“适合谁”，是“专门拍给谁看”。

如果回答是“泛人群吧，男人女人都行，先跑跑看数据”——那说明方向根本还没想清楚。

真正能持续高转化的内容，一定是“偏心”的。 它必须精准踩中某一类细分人群的审美、痛点和语言体系。除非你卖的是大米、纸巾这种全民刚需，否则“谁都适合”往往意味着“谁都不在乎”。

# 问题二：用户为什么会在前3秒停下来？

不要听“开头挺吸引人”“现在大家都这么拍”——这是废话。

要的是一个具体的、可拆解的理由：

- 是吐槽？戳中了什么共鸣？

- 是冲突？谁和谁对立？

- 是反差？哪两个极端放在一起？

- 是信息悬念？什么话没说完？

如果连这个都说不清楚，那这个开头就是“凭感觉”——没有逻辑支撑的前3秒，后面拍得再精美也是白搭。

# 问题三：如果这条视频不出单，最可能卡在哪里？

这是一个反推型的风险预判题。

真正懂内容的人，一定能在视频发出去之前，就列出3个以上可能的“死因”：

- 人群切得太窄？

- 卖点讲得太绕？

- 原生感不够，像广告片？

- 节奏拖沓，用户等不到高潮？

如果只能说“跑跑看吧，看系统给不给量”——那你们团队对“结果怎么来”根本没有掌控力。把命运交给算法的人，算法从来不会手下留情。

# 问题四：这条视频，更像“内容”还是更像“广告”？

这个问题直接决定你的GMV Max能不能跑动。

你需要一套做“内容”的方法论，而不是做“素材”的流水线。

什么是内容？

- 开头像在跟老外朋友聊天，而不是对着镜头喊促销；

- 节奏、置景、口吻，透着“原生感”；

- 用户看完觉得“这人挺懂我”，而不是“这商家想赚我钱”。

如果你团队从来没讨论过这个问题，那你们拍出来的大概率只是“广告素材”——系统连测试的机会都不愿多给。

# 问题五：如果数据不好，下一步打算怎么改？

这是区分“执行者”和“操盘手”的黄金问题。

对结果负责的人，一定已经提前想好了备选方案：

- 是换开头？换哪一类钩子？

- 是换卖点？主打功能还是主打情绪？

- 是换人群？从职场女性切到精致妈妈？

- 还是保留卖点、只换场景？从办公室搬到卧室？

如果回答是“那就再拍几条，多上点素材”——本质是用“量的勤奋”掩盖“质的判断力缺失”。

算法从来不奖励盲目堆料，它只奖励“知道自己为什么赢、为什么输”的人。
