# TikTok 短视频素材 AIDI 模型

### TikTok 短视频素材 AIDI 模型

（作者：Richmond，10月8日修改 \| 适合达人/自户内容，方便标准化执行）

#### A — Attention（吸引注意）

- **目标**：前1\-3秒快速抓住用户眼球，避免划走

- **常见做法**：

    - 夸张对比：前后对比（脏vs干净，慢vs快，难vs易）

    - 冲击画面：产品极限测试、特殊视角、强声音效果

    - 热门开头：用流行梗、反向句或“不要买这个…”开场

- **素材拆解点**：封面/开场3秒是否能直观表现痛点或效果？

#### I — Interest（激发兴趣）

- **目标**：让用户明白“这是什么”，建立初步好奇心

- **常见做法**：

    - 展示关键卖点（轻便/功能全/价格对比）

    - 演示场景（厨房、卧室、户外DIY等真实使用）

    - 达人实测（短视频快速验证效果）

- **素材拆解点**：卖点表达是否通俗直观？场景是否贴合目标人群？

### D — Desire（制造渴望）

- **目标**：让用户觉得“我也需要”

- **常见做法**：

    - 痛点解决：突出“省时、省力、省钱”

    - 情感代入：例如“女生自己也能轻松装家具”

    - 社会认同：好评截图、多人使用场景

- **素材拆解点**：是否给用户提供“带入感”或“立刻购买的理由”？

### I — Interaction（引导互动/行动）

- **目标**：推动转化 \& 提升视频互动率

- **常见做法**：

    - 口播或字幕：“链接在这”“点一下就能买到”

    - 弱召唤\+自然收尾：“用了之后我再也不用找人修了”

    - 评论区互动引导：“你会用在哪个场景？”

- **素材拆解点**：结尾是否有互动引导？购买召唤是否自然不过度？

### 模型应用

1. **脚本设计**：拆解每个环节至少一个执行动作（比如 Attention →“极限测试画面”）。

2. **复盘分析**：对爆款/普通视频打标签，看是卡在 Attention 还是 Desire 环节。

3. **达人执行**：给达人脚本时，直接对应 AIDI 模型的4步结构，避免素材跑偏。
