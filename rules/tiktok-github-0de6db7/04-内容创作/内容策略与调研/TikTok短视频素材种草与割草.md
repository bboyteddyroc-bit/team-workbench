# TikTok短视频素材种草与割草

文档日期：2026/05/23

## 核心观点

- **错误思路**：把种草和割草视频简单按比例（如3:7、5:5）分配。 

- **正确思路**：视频分配应根据 **人群认知阶段、市场教育程度、竞品情况** 调整，而不是固定比例。 

- **融合策略**：种草与割草可以相互融合，优秀的视频往往包含两者元素。 

## 一、判断阶段：种草还是割草？

### 市场未被教育（新品阶段）

- **核心策略**：以种草为主，减少直接卖货。 

- **目标**： 

    1. 让目标用户停留 

    2. 避免反感 

- **执行要点**： 

    1. **前三秒抓住用户注意力**： 

        - 地道开头文案（老外日常语言） 

        - 用户感兴趣的话题 

        - 悬念、冲突、趣味元素 

    2. **内容感卖货**： 

        - 场景道具自然合理 

        - 卖点自然衔接 

        - 灯光、节奏自然流畅 

- **注意事项**： 

    - 不做大规模品牌教育 

    - 避免过早突出价格优惠或硬性成交 

**示例**：

- 展示厨房收纳架使用场景 

- 先展示效果和便利性 

- 视频结尾自然引导购买：“如果你也想让厨房更整齐，链接在下面” 

### 市场已教育（已有竞品，人群知晓产品用途）

- **核心策略**：以割草为主，提供明确购买理由。 

- **目标**： 

    - 给用户一个“成交出口” 

    - 提高转化率 

- **执行要点**： 

    1. **明确卖点**： 

        - 产品独特功能 

        - 价格优势或促销 

        - 用户痛点解决方案 

    2. **保持原生感**： 

        - 场景真实自然 

        - 推销语气自然 

        - 给予用户信任感 

- **注意事项**： 

    - 不要继续重复种草内容 

    - 可保留轻微故事或趣味元素 

## 二、种草与割草的融合技巧

**原则**：

1. 种草视频结尾引导购买，不只是讲故事 

2. 割草视频保留可信度和原生感 

3. 优化核心：精准的人群判断 \+ 用户信任度 

## 三、素材结构优化思路

1. **判断人群认知阶段**

    - 新用户：以种草为主 

    - 已教育用户：以割草为主 

2. **结合市场情况**

    - 教育强、竞品多：加大割草比例 

    - 市场刚起步、竞品少：以种草为主 

3. **视频内容融合**

    - 种草视频结尾引导购买 

    - 割草视频保持原生故事感 

4. **最终目标**： 

    - 高播放 \+ 高转化 

    - 通过精准判断和信任感优化素材结构，而非视频数量比例
