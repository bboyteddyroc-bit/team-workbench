# 怎样找到和分析蓝海市场？

**怎样找到和分析蓝海市场？**

#### **个人卖家选品经常遇到什么难题？**



1、投入成本不高

2、竞争分析不准

3、定位资源不清晰

4、容错率低



最重要是什么？分析的思路和方法碎片化。

在选品早期，一定要做的是多维度多方法的分析。

今天我给大家介绍一套比较能快速分析和定位蓝海市场、细分赛道的方法。

#### **什么是蓝海市场？**

覆盖非绝大多数人群的持续性需求

竞争小

利润高



##### **为什么说持续性需求？**

因为不持续的需求，会给备货和销售带来巨大的风险，这也是我们选择蓝海产品时候一定要验证清楚的。



#### **如何找到新的蓝海赛道方向？**

##### **站内工具指标筛选？**

趋势成长期：增长率20%以上

客单价30美金以上

Top100新品占比10%以上

CPC对比

等等。

然而这些标准化的操作，非常多的卖家都在做，这也是造成同质化的原因之一，选品的路径雷同。

区别于指标筛选，今天要讲的是妥妥的纯纯的蓝海查找，因为我始终觉得，想做第一个吃螃蟹的人，要找到用户关注点的变化方向和风口。
