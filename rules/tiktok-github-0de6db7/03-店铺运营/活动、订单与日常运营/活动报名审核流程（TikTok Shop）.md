# 活动报名审核流程（TikTok Shop）

# **活动报名审核流程**

### **一、活动信息获取（每两日复查）**

**责任人：运营负责人**
**时间：每日 12:00 前**

**必做：**

1. 查看 TikTok Shop 后台活动页（Campaign Center）。

2. 查看平台运营群、类目经理群的新活动通知。

3. 判断活动是否与店铺品类匹配（品类、客单、库存、物流时效是否达标）。

### **二、初步筛选（必须量化）**

**责任人：运营负责人**
**时间：活动发布后 2 小时内完成**

**筛选标准：**

1. **符合类目？**（是/否）

2. **是否提升访问或转化？**（高/中/低）

3. **是否占用额外成本？**（佣金提升、满减门槛、折扣要求）

4. **是否能保证库存与发货？**（库存≥活动期预估销量的 2 倍）

5. **产品是否有 4\.5 星\+评价？**

6. **过去30天 GMV/点击成本数据是否适合参加？**

**不满足其中2项以上:直接筛掉，不报名。**

### **三、报名准备（最关键的一步）**

**责任人：运营负责人 \+ 美工/内容团队**

**要求：**

1. **活动价格测算**

    - 目标 ROAS、目标毛利率

    - 活动价要保证至少 \>15% 毛利（美区别亏）

2. **库存校对**

    - 活动期预计销量（按历史活动表现×1\.8\-2倍算）

    - 供应链确认是否能补货\(补货周期）

3. **商品卡优化**

    - 更新封面图

    - 更新卖点文案

4. **内容准备**

    - 活动开始前至少准备 3 条新内容：

        - 1 条卖点类

        - 1 条场景类

        - 1 条强视觉冲击类

    - 如 GMV Max 配合活动：提前准备加热素材

### **四、后台报名（严格复核）**

**责任人：运营负责人\-上报主管审批**
**每项需二次复核，不得单人操作**

**复核点：**

1. **活动价是否正确？**

2. **报名链接是否正确？**

3. **库存同步是否完成？**

4. **物流模板是否匹配活动区域？**

5. **店铺表现是否符合活动要求（取消率、延迟发货率、纠纷率等）？**

### **五、活动结束复盘**

**责任人：运营 BD 内容**

**复盘结构：**

1. 活动 GMV \& ROAS

2. 消耗 vs 转化

3. 活动期间内容表现

4. 价格策略是否合理

5. 后续建议（是否继续报名类似活动）
