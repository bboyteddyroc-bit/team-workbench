# TikTok账号登录前的维护及注意事项

#### 1\. 检查本地无线网络连接

若网络异常：

- 先忘记当前网络并重新连接；

- 若仍失败，执行手机网络重置：

    1. 打开设置；

    2. 点击通用（General）；

    3. 选择传输或重置iPhone；

    4. 点击重置（Reset）；

    5. 选择重置网络设置（Reset Network Settings）。

#### 2\. 验证VPN连通性

通过“小火箭”工具测试延迟，确保代理网络稳定。

#### 3\. 检查IP与伪装度

打开Safari浏览器，访问whoer\.net：

- 确认设备IP与VPN代理IP一致；

- 设备伪装度需≥90%（100%最佳，不影响正常使用）；

- 若出现“连接有风险”提示：

    1. 将设备时间设为自动；

    2. 打开App的广告个性化推荐；

    3. 刷新网页；若仍无效，执行网络重置。

#### 4\. 登录后的初期操作

进入TikTok后，先刷一段时间视屏（避免直接发视频），防止系统判定为异常行为；“只输入不输出”（仅浏览不发布）会对账号权重产生负面影响。

#### 5\. 使用后的后台管理

正常使用后，需关闭TikTok后台进程（因VPN稳定性有限，避免断网导致账号环境异常）。
