# 如何写listing

## 一、Listing的组成

在跨境电商平台上，Listing是消费者看到的第一个品牌接触点，是产品页面的展示形式。无论是亚马逊、TikTok Shop，还是Temu或独立站，一个好的Listing能让产品获得更多的曝光和更高的点击率。Listing包含：**产品标题、图片、描述、价格、客户评价**等，所有这些因素共同决定了产品能否吸引顾客购买。

## 二、如何评价Listing的好与坏

- **曝光度**：产品在搜索结果中的排名。数据来源：店铺后台数据统计

- **点击率**（CTR）：精心设计的标题、主图和视频能提高点击率。数据来源：店铺后台、广告后台数据统计

- **转化率**（CVR）：精准的描述、清晰的功能卖点和令人心动的价格会直接影响顾客是否最终购买。数据来源：店铺后台、广告后台数据统计

## 三、Listing的基本要求

**标题不合格案例：**

1）关键词重复 反复出现多次

2）标点符号乱用

3）核心词的首字母有的大写 有的小写

4）卖点完全不清晰

#### 各平台格式规范与禁忌（TikTok规则每月更新）

TikTok：

✅ **必做项**：

字符数控制（移动端首行显示完整）

每个单词首字母大写（介词/冠词除外）

使用阿拉伯数字

**禁忌项**：

关键词反复使用堆砌

特殊符号：禁止使用\.\.\.\. \!❌ ★等（会触发审核）

主观形容词：如"Best Quality"/"Cheap"（违反政策）

营销词：节日词例如Mother's Day, Spring Campaign（违反政策）

尺寸单位混用：统一用英寸/厘米（如15\.6 Inch而非15\.6"）

## 四、如何写Listing

#### 4\.1 竞品分析 【核心对标链接3个对应一个品，各销售渠道一周复盘一次】

**为什么要做竞品分析**：

竞品分析帮助你快速熟悉行业、了解市场需求、确定核心竞争力，并为Listing优化提供数据支持。

通过分析竞品，你可以发现自己Listing的优势和不足，抓住市场空白点，承接竞品的外溢流量。

**如何选择竞品**

跟我们的产品高度相似（外观、功能、场景、人群）

排名靠前：老链接类目排名Top 10以内，链接上架超过4个月以上/新链接Top 5以内，链接上架3个月以内（国际大牌不做参考！）

**竞品分析的主要内容**：

**产品标题**：竞品的属性词、关键词、精准流量词、长尾流量词（场景词、人群定位词）

**产品描述和卖点**：竞品品名、卖点、目标人群、产品规格、适用场景。其中埋入标题的关键词和描述词是什么

**价格和促销**：竞品定价如何？是否有促销活动？

**客户评价**：分析顾客对竞品的评价，了解市场需求和痛点。

**主图和商详：**竞品主图展示的要点，商详的顺序排布，具体产品使用场景，画面突出的质感

每个产品在不同电商平台的竞品明细

#### 4\.2 关键词库 

**什么是关键词**：

**关键词**：指的是用户在搜索引擎或电商平台上输入的词语或短语，用来找到特定的产品。关键词通常分为几类，帮助你在各大平台的搜索结果中提升排名。

## 商品描述 详情页

买家希望了解商家的商品与其竞品的差别。商家通过对商品进行描述，可以提供商品名称中没有完全涵盖的额外信息。

为确保商家通过优质的商品描述帮助买家了解商品，商家应遵守以下标准：

- 清楚描述商品的主要特点、特征以及用途。

- 写明商品的准确尺寸、保养指南以及保修详情。

- 描述清晰，有助于买家了解商品。使用正确的语法、标点和完整的句子。 

- 不少于30个字。

- 不得使用模糊的陈述，描述商品特点和属性时要力求具体。

- 不得包含商家名称或任何其他具体的商家信息、电子邮件地址、网站链接（URL）或其他商品的信息。

建议在商品描述中使用3至5个分条阐述要点。如果选择使用分条阐述要点，请注意以下额外的格式要求。

- 重点突出希望买家注意的主要特点和功能，包括但不限于：

    - 目标年龄或人群

    - 保修信息

    - 尺寸

    - 商品用途

    - 成分

- 每条要点都以大写字母开头

- 提供不带标点符号或符号的尺寸详情。

- 使用数字标明商品的适用年龄范围。

- 注明商品的原产国/地区。

- 不得输入与公司相关的信息，此部分仅用于描述商品特点

- 使用计量单位全称，例如夸脱（quart）、英寸（inch）或英尺（feet）。

商家有责任确保商品描述包含所有适用法律法规要求的商品信息，包括但不限于商品安全信息、规格和警告。商家提供的所有信息都必须准确和真实。严禁任何具有误导性的商品信息。
