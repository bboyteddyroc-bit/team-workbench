# 团队创作中台 · Team Workbench

团队视频生产与内容研究工作台：从素材入库、竞对研究、AI 辅助创作，到生成、剪辑、配音、导出和飞书归档。

此仓库保存网页前端、Python 后端、规则与开发文档。GitHub 保存代码版本，不会因此把运行中的中台部署到云端，也不包含团队的业务数据备份。

## 功能地图

| 板块 | 功能范围 |
| --- | --- |
| 首页与登录 | 模块画廊、图标导航、交互登录入口、成员登录、飞书授权入口 |
| 素材管理 | 人物、产品、场景、视频、音频、其他六类素材；上传、拖入、搜索、缩略图、自动分类、制作台引用 |
| 制作台 | 多创作卡片、普通生成、参考素材、首尾帧、接力生成；公司 TikTok 账号池和 LibTV 通道；模型参数、任务追踪、结果预览、下载及加入剪辑 |
| 剪辑台 | 实拍与生成素材、多轨时间轴、裁剪分割、框选、吸附、撤销重做、组合与复合片段、字幕文本、动画、变速、贴纸、工程保存与版本 |
| 配音与音频 | 音色浏览搜索、试听和收藏，文案配音、音频入库、音轨编辑；具体服务依赖管理员配置 |
| 导出与交付 | MP4 命名与导出队列、结果预览下载、飞书个人文件夹按日期归档、手机素材传输及成品下载 |
| AI 助理 | 浮动对话、文件与图片输入、账号隔离的上下文与记忆、规则加载、生图入口、AI 剪辑提案 |
| 竞对账号 | 团队与个人监测、成员筛选、视频采集、指标快照、采集状态与异常处理 |
| 内容复用 | 视频链接入库、基础指标与商业数据补充、视频与评论分析、标签、镜头回看与精准定位、个人复用意见 |
| 商品与店铺 | 从视频关联商品店铺、详情补查、经营指标、相关达人和带货视频、识别记录与结果复用 |
| 自营商品 | 商品档案与标签、样本关联、综合证据报告、需求与购买意图、场景、阻力、内容表现及可复用镜头，结论可追溯来源 |
| 脚本运营 | GMV 贡献、爆款文案库、风险表达库、脚本任务、异常任务、Kalodata 查询、数据接入等界面与接口；具体接通范围见详细说明 |
| 管理 | 公司账号池、独立 LibTV 多账号配置、团队成员与权限、密码管理、操作记录、存储管理、服务配置 |

这是功能导航，不是所有外部服务都可用的保证。采集、AI、生成、飞书等需要有效授权、网络和额度；缺失数据不等于零，分析结果不是销量保证。历史说明可能保留阶段记录，应结合后续修订与当前代码核对。

## 上传范围与排除项

已纳入：后端业务代码、前端源文件和界面静态资源、测试、选定启动脚本、规则与核心文档。Kalodata 依赖以子模块引用，需要递归克隆。

有意不上传：`state/`、数据库、账号密码和授权、API key、Cookie、私钥、真实素材、生成成片、音频缓存、日志、抓包、虚拟环境、安装依赖和第三方可执行文件。独立桌面客户端项目和安装包不在本仓库。历史原型、暂存改稿、截图及一次性更新目录也不属于当前运行源码基线。

**本地正在由其他任务修改的文件不会未经检查一起提交。仓库是已提交版本，不等同于任意时刻本机目录的完整镜像。**

## 开发环境与启动

1. 递归克隆仓库，初始化 `vendor/kalodata-skill` 子模块。
2. 建立项目 `.venv`，安装 `requirements.txt`。
3. 安装 FFmpeg/FFprobe 与所需 LibTV CLI；这些程序未放入 Git。部分执行脚本使用 `tools/ffmpeg-7.1.1/ffmpeg-7.1.1-essentials_build/bin` 和 `tools/libtv-1.2.0`，迁移时核对路径。
4. 配置本机数据位置、服务授权、网络和 HTTPS 证书。已有团队迁移还需单独迁移数据库及其加密密钥，不能只复制源码。
5. 开发入口为 `python -B app.py`，或在 Windows 使用 `start.ps1`。当前生产执行机使用 `run_service.py local|lan`；其中地址和端口带本机配置，换机器前须核对。`local` 不执行生产队列，LAN 服务负责相应后台任务。

不要同时启动多套生产队列执行器。Git 提交、推送与运行服务重启是不同动作。

## 后续更新如何同步

每次功能改动完成后，检查差异、敏感信息和相关验证，只提交本次完成的文件，再推送到 GitHub。功能、权限或操作变化同步维护 `docs/AI_FEATURES.md`，执行 `python -B sync_ai_readme.py` 更新 AI 说明。本仓库没有“任何文件保存后立即上传”的后台同步器。

本 README 是当前功能总览，不能替代运行验收；测试与上线情况以具体更新记录为准。
